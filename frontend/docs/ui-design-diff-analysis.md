## 1. 设计稿界面概述

设计稿包含两个移动端页面：

### 页面 A：设置（Settings）
- **顶部**：返回箭头 < + 标题「设置」
- **列表项**（cell 样式，右侧带 > 箭头）：
  - 账号与安全
  - 收货地址
  - 关怀模式（显示状态：未开启）
  - 通知设置
  - 清理缓存（显示数值：11.9 MB）
  - 通用
  - 登录设备管理
- **分组分隔线**
- **隐私分组**：
  - 隐私
  - 个人信息收集清单
  - 第三方收集清单
- **分组分隔线**
  - 关于我们
- **底部**：「退出登录」按钮（全宽，居中文字）

### 页面 B：个人信息（Personal Info）
- **顶部**：返回箭头 < + 标题「个人信息」
- **列表项**（cell 样式，右侧带 > 箭头）：
  - 修改头像（右侧显示头像缩略图）
  - 修改昵称（右侧显示当前值：学员07dslj）
  - 修改密码
  - 更换手机号（右侧显示脱敏手机号：137******12）
  - 注销账号
  - 我的账号
- **底部**：「退出当前账号」按钮（红色文字，居中）

## 2. 当前代码界面结构

当前代码通过以下组件实现：

| 组件 | 路径 | 职责 |
|------|------|------|
| SidebarLayout | layouts/SidebarLayout.vue | 桌面端侧边栏 + 主内容区布局 |
| AppSidebar | components/layout/AppSidebar.vue | 侧边栏导航、用户信息、退出登录 |
| Profile.vue | pages/student/Profile.vue | 个人资料编辑页 |
| ProfileEditDialog | components/layout/ProfileEditDialog.vue | 修改昵称/头像弹窗 |

### Profile.vue 当前实现
- **布局**：卡片式（l-card）分组，表格描述列表（l-descriptions）
- **分组**：基本信息（UID / 账号 / 昵称 / 单位）、联系方式（手机号 / 邮箱）、账号密码
- **交互**：行内编辑按钮 → 弹窗（l-dialog）表单

## 3. 差异对比矩阵

| 维度 | 设计稿 | 当前代码 | 差异等级 |
|------|--------|----------|----------|
| **整体布局** | 移动端全屏列表页，带顶部导航栏（返回+标题） | 桌面端侧边栏布局，内容区嵌入卡片 | 🔴 架构级 |
| **页面拆分** | 两个独立页面：「设置」+「个人信息」 | 单一页面：「个人资料」合并展示 | 🔴 结构级 |
| **导航模式** | 顶部返回箭头 + 页面标题 | 左侧固定侧边栏 + 路由菜单 | 🔴 架构级 |
| **信息展示** | Cell 列表（白色行 + 灰色分隔线 + 右箭头 >） | l-card + l-descriptions（带边框表格） | 🟡 视觉级 |
| **退出登录** | 设置页底部独立按钮（全宽居中） | 侧边栏顶部下拉菜单中的菜单项 | 🟡 交互级 |
| **分组方式** | 通过分隔线自然分组，无卡片边框 | l-card 卡片标题分组 | 🟡 视觉级 |
| **用户信息** | 个人信息页：头像/昵称/手机号/账号独立 cell | Profile 页：UID/账号/昵称/单位/手机/邮箱混合 | 🟡 结构级 |

## 6. 信息架构差异

### 设计稿的信息层级
`
设置（Settings）
├── 账号与安全 ──→ 个人信息（子页面）
│   ├── 修改头像
│   ├── 修改昵称
│   ├── 修改密码
│   ├── 更换手机号
│   ├── 注销账号
│   └── 我的账号
├── 收货地址
├── 关怀模式
├── 通知设置
├── 清理缓存
├── 通用
├── 登录设备管理
├── ── 分隔 ──
├── 隐私
├── 个人信息收集清单
├── 第三方收集清单
├── ── 分隔 ──
├── 关于我们
└── 退出登录
`

### 当前代码的信息层级
`
侧边栏
├── 用户头像/昵称（下拉菜单 → 退出登录）
├── 导航菜单
│   ├── 仪表盘
│   ├── 课程中心
│   ├── ...
│   └── 个人资料 ──→ Profile.vue
│       ├── 基本信息（UID / 账号 / 昵称 / 单位）
│       ├── 联系方式（手机 / 邮箱）
│       └── 账号密码
└── 收起侧栏 / 通知
`

**关键差异**：
1. 设计稿采用**设置→个人信息**两级导航，当前代码将所有信息平铺在单一页面
2. 设计稿的「退出登录」在设置页底部，当前代码在侧边栏下拉菜单中
3. 设计稿的「账号与安全」作为入口指向子页面，当前代码直接展示所有字段

## 7. 实施建议

### 阶段一：页面拆分与基础搭建（P0）
1. **创建设置页** pages/student/Settings.vue
   - 移动端优先的列表布局
   - 顶部导航栏（返回 + 标题）
   - Cell 列表组件（可复用 SettingsCell.vue）
2. **重构个人信息页** pages/student/PersonalInfo.vue
   - 从 Profile.vue 拆分
   - 头像、昵称、密码、手机号独立 cell
   - 注销账号功能
3. **路由配置**
   - /training/settings → Settings.vue
   - /training/settings/personal-info → PersonalInfo.vue

### 阶段二：功能补齐（P1）
4. **账号与安全**子页面
5. **登录设备管理**页面
6. **通知设置**页面

## 9. 与现有系统的兼容性考虑

1. **桌面端适配**：设置页在桌面端可作为侧边栏内嵌面板，或独立路由页面
2. **现有 Profile.vue 迁移**：保留原有功能入口（UID、单位等），逐步迁移到新结构
3. **API 兼容**：新页面复用现有 uthApi 接口，无需后端改动
4. **渐进式重构**：可先新增设置页，旧 Profile 页保留并添加重定向
