# 学员资料投稿区：推翻「不建独立资料库」，确立积分供给闭环

背景：ADR-0018 曾定「学习资料＝课程附件的聚合视图，不建独立资料库」。学员希望上传资料换取积分，若沿用旧口径，投稿要么挤进课程附件（供给侧越权），要么无处安放（积分无从定价）。

决定：新建**资料投稿（contribution）**域作为课程附件之外的第二资料来源——学员上传 1–5 个文件（单文件 ≤20MB、投稿 ≤50MB），必挂目标证件、跟随全局证件过滤器；`pending→approved/rejected` 先审后发（后端 tutor+admin 同鉴权，V1 前端仅管理端队列），过审即时直记 +50，下载达阶（10/50/200 次，每人每稿终身一次为事实源）追加 +30/+80/+200，全部走 ADR-0023 幂等占坑与站内信；违规下架进 archived 并用 rollback 追回已发积分（封底 0）。消费侧 V1 免费下载——下载不是消耗事件，redeem 管线保持学员→平台单向。治理面自带 contribution_report（照 job_reports 先例，不挂论坛举报表），供给面背压为日 ≤3 份＋pending 积压 ≤5 份，资格仅限已选定当前证件的学员（讲师/管理员仍走课程附件通道）。

理由与权衡：积分激励必须有可被消费的资产作定价锚点，「仅归档不可见」或「糊进论坛帖子」都撑不起「值多少分」的语义。代价是新增浏览面（/training/materials 页加「学员投稿」tab）、一张审核队列、一个达阶结算点与文件暂存回收（复用论坛悬空图片守护模式）；换来供给侧从单向（讲师）变双向。否决项：付费下载＋作者分成（引入 P2P transfer 语义，ledger reason 体系无此类型，小号互刷凭空造分）；免审白名单（「信誉」是未定义新词，且开刷分通道）。
