# ADR-0099：市场样本校准专用匹配器——分层降级、中位数、残值率标签

- 状态：Accepted（2026-11-19）
- 日期：2026-11-19
- 领域：残值评估 / 数据采集（市场真值）
- 票：#2675（实施）· 父规格 #2671 · 承接 ADR-0098

## 背景

ADR-0098 把拍卖公告抽成结构化规格并把噪声分流，下一步要给样本打上「残值率 = 成交价 ÷ 匹配原价」弱标签，供后续校准拟合。 spec #2671 与 wayfinder #2661/#2667 已裁定：校准匹配器按 7→4→3 字段分层降级、多命中取原价中位数、记录匹配层级与原价区间，并且**明确不复用评估路径的模糊匹配**——后者取 `ORDER BY original_price DESC LIMIT 1`（最高价），对评估是保守取向，对残值率标签却是系统性压低偏差源。本票把这份裁定落成独立、纯函数、版本化的匹配器。

## 决策

**一、独立纯函数匹配器，不复用评估路径。** `collector/match/matcher.py` 的 `match(sample, candidates)` 是纯函数：只读已抽取清洗的 `RawSample` 与原价候选列表，用 `dataclasses.replace` 产出新样本，不改入参、不碰网络。评估路径 `backend/internal/valuation/` 与 `dict_original_prices.go` 的 `FindOriginalPriceFuzzy`（取最高价）零改动（本票 diff 对该目录为空，valuation 测试全绿）。匹配器是独立实现，语义与评估路径分离。

**二、7→4→3 字段分层降级，各层可审计。** 匹配按可用键从强到弱依次尝试：精确 7 字段（照 `original_prices` 的 brand/vehicle_type/series/tonnage/config_type/mast_type/mast_height_mm）→ 品牌+车型+系列+吨位 → 品牌+车型+吨位。每一层都**逐字段比对候选值**与样本值（不是只查列存在）——`original_prices` 全列 NOT NULL，若只查存在会让真表每一行都误命中、中位数被无关规格的高价污染。抽取侧产物 `model` 与原价表列 `vehicle_type` 视为同一「车型」信号（用 `or` 回退，`vehicle_type=None` 也回退到 `model`）。命中层写入 `match_level`（`exact7` / `brand_vehicle_series_tonnage` / `brand_vehicle_tonnage`），三层各有录制 fixture 覆盖，契约测试在真 PG 上逐层断言。

**三、多命中取中位数 + 记录原价区间，区间宽度进可信度。** 同层多条命中取原价**中位数**（偶数条取两中间值平均），不是最高价。`matched_original_range` 记 `min/max/count/width`；可信度 `1/(1+width/median)` 写入 `field_confidence["matched_original_price"]`——区间相对越宽可信度越低，单命中 width=0 则可信度 1.0。匹配得率/置信度不设硬门槛（沿用「记录为事实、不设门槛」口径），只如实产出。

**四、残值率 = 成交价 ÷ 匹配原价；未匹配保留标签资格、标签留空。** 有匹配且原价 > 0 时写 `residual_rate_label = raw_price / matched_original_price`（与公式输出同纲）。`raw_price` 来自抽取阶段、可能是挂牌价或成交价（`raw_price_kind` 区分）；本票不按 `raw_price_kind` 分叉，残值率口径统一为「原样价格 ÷ 匹配原价」——挂牌价与成交价的语义区分留给下游校准按 `raw_price_kind` 加权/筛选，此处不新增判定门槛（沿用「记录为事实、不设门槛」口径）。未匹配样本 `match_level`/`matched_original_price`/`residual_rate_label` 留空、`matched_original_range={}`，但**不改 `label_eligible`**（该列语义仍是「价格抽取成功」）；标签为空由 `market_transactions` 的 partial index 自动排除出校准集。补入原价后可由 `collector rematch` 重跑回收标签，不重爬、不动抽取/清洗列。清算折扣 δ 在下游校准拟合时应用（基线 0.85 + 敏感性），本管线只存原始价格与未折扣的残值率。

**五、配置直读 + 版本落库 + 录制打桩契约测试。** 原价候选从 PG `original_prices` 表直读（与后端 eval 读同一张真表），注入纯函数 seam；契约测试在随机 schema 内播种子表，端到端断言分层/中位数/残值率/区间/版本落库。匹配版本 `MATCH_VERSION`（当前 `v1`）写入迁移 000066 新增的 `market_transactions.match_version`，与 `extraction_version`/`clean_version` 对称，使「这行是哪版匹配器打的标签」可审计、规则升级可分离重跑。契约测试用录制抽取输出打桩（确定性、不测 prompt 质量）；分层/中位数/区间/残值率/未匹配的纯判定用 `python3 -m unittest discover`（与 deploy/tests 同 runner）。

## 被否备选

- **复用评估路径 `FindOriginalPriceFuzzy`**：其取最高价会对残值率系统性压低偏差，且评估路径不得改动——独立实现才能分离语义。
- **只按精确 7 字段匹配、不降级**：拍卖公告规格抽取常缺 config_type/mast_*，硬匹配会让大量样本无标签、校准集太小。
- **多命中取最高价 / 第一个**：最高价即评估路径偏差源；第一个不稳定。中位数抗离群。
- **未匹配样本 `label_eligible=false`**：会把「价格抽取成功」与「有匹配标签」两个语义混淆，丢失「样本可用只待补原价」的信息。
- **把匹配可信度单独建列**：`field_confidence` 本就是逐字段置信度的归属，另建列是第二份真相。
- **匹配版本不落库**：与 `extraction_version`/`clean_version` 不对称，无法回答「这行标签是哪版匹配器打的」，规则升级不可分离重跑。
- **匹配得率设硬门槛**：沿用「记录为事实、不设门槛」口径，门槛属下一轮校准拟合的决策，不在此立。

## 后果

**收益**：①残值率标签口径与评估路径解耦，避免取最高价的系统性偏差；②分层 + 中位数 + 区间 + 版本全落库，校准集可按层级/置信度/版本筛选与重跑；③未匹配样本可经 `rematch` 回收标签，无需重爬公告。

**代价**：①新增 `collector/match/` 子包 + 迁移 000066 + 两个录制 fixture；②`vehicle_type`/`model` 字段别名依赖抽取产物命名一致，若换抽取 prompt 需同步；③中位数/区间可信度是初版启发式，边界样本靠抽检与下游校准兜底，不设硬门槛。

**实施边界（本票不做）**：校准拟合（含 δ 应用与敏感性）、未匹配待审队列消费 / 复核 UI（#2676）、历史公告批量回补（#2677）、daemon 增量模式、抽检队列 UI、评估路径改动——全部在后续票或独立工作。本票只交付「已清洗样本 → 分层匹配 → 残值率标签写回 / 未匹配留空」这一段；评估记录表与评估路径零改动。
