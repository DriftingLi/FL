# ADR-0058: 课程与章节的可见性覆盖「按 id 读路径」

- 状态：已接受（2026-09-18，#1132 复审 Q2 = A 裁定）
- 领域：学员可见性口径（课程挂载不变式）/ 按 id 读路径 / 收藏与学习记录的快照语义
- 前置登记：ADR-0049 已为**题目域**确立「可见性口径覆盖每一条读路径（作答抽题、搜索结果、按 id 取详情）」；本条把它补到**课程域**，并把 ADR-0050 §1 的谓词单点扩到第三个形态。

## 背景

学员可见性谓词（挂载不变式 `specialty_id IS NOT NULL AND level_id IS NOT NULL` + `status = 1` 已发布）由 `service/course_mount_scope.go` 单点承载。收紧前它的消费方**只有发现面**（学员课程列表、搜索的课程/章节分区、收藏的写时校验），而**按 id 取内容的读路径不做判定**：

- `GET /api/course/:course_id` → `GetCourseDetail`（`course_service.go`）只校验课程存在；
- `GET /api/course/:course_id/chapter/:chapter_id` → `GetChapterDetail` 只校验「章节存在 + 归属该课程」；
- `GET /api/chapter/:chapter_id/slides` → `GetChapterSlides` 同（该端点原为**公开访问**，鉴权已在 #1132 复审中收回）。

⇒ 未发布 / 未挂载的课程与章节，**只要知道 id 就能被学员读到**（课程名、章节列表、正文、PPT 全量），而列表与搜索里看不到 —— 一个没有任何守护会变红的静默不一致。生产实测（2026-09-18）：课程 8 门全部已发布且已挂载、`chapter` 有外键且 0 孤立 ⇒ 该缺口当时**没有可泄露对象**，属「口径未声明」而非「正在发生」。

## 决策

1. **课程与章节的按 id 读路径纳入学员可见性谓词**：`GetCourseDetail`、`GetChapterDetail`、`GetChapterSlides` 一律要求「已发布 + 已挂载」；不可见按「不存在」返回（404），前端落既有空态。
2. **谓词仍单点**：在 `course_mount_scope.go` 增加 by-id 形态 `CourseVisibleByID`（该单点里唯一把挂载与已发布叠好的形态），全部消费方复用它，不手拼谓词。
3. **接受已知代价**：收藏 / 学习记录是**快照语义**（写时校验、读时不因目标状态变化而消失）⇒ 目标后来被撤挂或下架时，列表里那条**仍在**、点开是空态。这是本决策有意换取的严格性，不是回归。
4. **不动的面**：收藏读面（快照）、管理端（`/admin/*`）、导师端（`/tutor/*`，各自接口）、课程列表与搜索（本就过滤）。

## 理由

- **同域先例**：题目域已按 ADR-0049 覆盖每一条读路径（draft / 源标记真题题 / 非当前证件一律 404）；课程域不覆盖属**域间口径不齐**，不是有意的差异。
- **未发布内容不该被知道 id 的人读到**：撤挂常发生在「建课过程中」；收紧后这类内容只在管理端 / 导师端可见。
- **代价可控且可见**：快照条目点开为空态，且空态已具备（Web 章节页 404 空态 + 「返回课程」，移动端同）。

## 被否备选

- **维持现状 + 写明「读面不设可见性校验 = 有意的快照可达性」**（复审中的 B 案）：口径自洽，但把「未发布内容可被深链读取」固化成设计，且与题目域先例相反。只有当运营确认「撤挂是常规动作、且不容忍收藏点不开」时它才更优。
- **读面分层：未发布 404、已下架仍可达**（复审中的 C 案）：需要区分「从未发布」与「发布后下架」，而 `status = 0` 与空挂载位无法区分二者，须先落 `published_at` / 下架审计等额外事实 —— 本轮不具备。
- **只收紧章节、不动课程**：会制造课程与章节之间的新不一致（同一门课，课程页打不开而章节页能打开，或反之）。

## 锁

- `backend/internal/api/course_read_visibility_contract_test.go`：9 条 —— 可见课程 / 章节 / 幻灯片三面各 200；未发布、未挂载两组 × 三面各 404（含「防收紧成一律不可见」的正例）。
- `TestChapterSlidesRequireAuthContract`（#1132 复审）：幻灯片无凭证 401 / 已登录 200。
- 既有夹具随之修正：`course_chapter_detail_test.go` 的课程夹具补挂载位（它测的是详情语义，本应以**可见**课程为夹具）。
