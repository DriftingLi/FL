# ADR-0006: 课程分类体系收敛（旧分类与知识点树退役）

- 状态：已接受（2026-08-07，课程目录体系重构 tickets #51/#52/#54/#57）
- 领域：培训 —— 课程与题库分类

## 背景

新课程目录体系（专业方向 × 课程等级 + 题库标签）上线后，与旧分类体系并存且互相冲突：

- 旧 `course.category` 四分类（CATEGORY_01~04）与新的方向/等级双轨并存，创建课程必须填 category 而新目录树不展示该字段；迁移时只回填一次，此后无同步机制，两套口径漂移；
- 旧知识点树（knowledge_point 表 + question.knowledge_point_id + 章节练习端点）与题库标签（question_tag + tag_relation + 标签练习）并存：题目挂知识点与打标签两套分类同时存在，导师建题与学员练习各有两个入口；
- 管理端两套课程界面（表格页 + 目录树页）操作同一批数据，出现 12 处已知 bug（编辑清空前置课程、学生端章节数恒空、新增标签必 400、排序对默认值无效等）。

## 决策

课程分类体系收敛到新维度，旧体系整体退役：

- **课程侧**：删除 `course.category` 列；课程创建/编辑必填专业方向 + 课程等级（应用层校验，DB 列保持可空兼容存量）；学生端列表与目录树统一只展示已挂载课程；
- **题库侧**：删除知识点树（knowledge_point 表、question.knowledge_point_id、章节练习/知识点练习/知识点管理端点）；存量题目按显式映射回填标签（知识点 1→结构、2→液压、3→法规、6→故障诊断，其余保持未打标由管理员批量补）；导师建题改打标签；
- **排序**：新建项自动排同级末尾（sort_order = max+1）；相邻交换走后端 swap 端点（组内重编号，同值默认也生效）；
- 数据库删除集中在迁移 000002（contract 阶段，代码退役先行）；down 可逆（恢复表/列，回填清理按映射标签范围）。

## 后果

- 单一分类体系：课程 = 方向 × 等级，题目 = 标签；学员端、管理端、导师端三端口径统一；
- 题库入口收敛为标签练习，导师建题只需打标，学习路径（专项/标签）无重复；
- 代价：存量未打标题目需管理员在题库标签页补标；迁移回滚路径（down）无法还原已删列中的原始值（恢复为 NULL，需备份恢复数据）。
