# ADR-0022: 真题套卷模型与全池隔离

- 状态：已接受（2026-08-29）
- 领域：培训域 / 真题套卷、题库抽题池、积分权益（承接 ADR-0021 的演进方向）

## 背景

真题练习页此前为占位（ADR-0021），导入管线（`cmd/import-reference-content`）已将外部资料 8 个真题源文件（N1 7 套 + 一级 1 套，约 219 题）解析入库并打 `real_exam` 标签。需要把占位页填充为真实套卷，支持逐题刷题与整卷限时考试两种作答形态，并按套积分解锁（每套 300 积分）。

## 决策

- **套卷模型**：`real_exam_paper`（credential 单归属分区，`UNIQUE(credential_id, source_ref)` 以源文件相对路径为导入幂等键）+ `real_exam_paper_question`（卷↔题多对多，`order_num` 维持卷内题序）。多对多的原因：跨卷同题干在导入去重后折叠为同一 `question` 行，一题可同时属于多卷。
- **内容由导入工具产出**：卷的生成/更新属于数据操作（`ApplyPapers`，按 文件→题目 映射 upsert、重建关联、同步 question_count），不进 migration；migration 只建表。碎片预览文件（< 最少题数，默认 3）不建卷。
- **双作答形态**：
  - 按卷练习：`GET /real-exam/papers/:id/practice`，复用 practice 基建——`practice_mode = "paper:<paperID>"`（`practice_progress` 断点续练，卷序固定不随机）、`POST /practice-mode/submit` 逐题判分（`practice_type = "paper"`）、错题自动进错题本。
  - 按卷考试：`POST /real-exam/papers/:id/exam`，固定题集 + 卷时长写 `mock_exam`（新增 `paper_id` 列归卷），之后的 save/resume/submit/result 原样复用 `/mock-exam` 端点。
- **全池隔离（is_source_tag）**：`question_tag.is_source_tag`（默认 FALSE，`real_exam` seed 为 TRUE）标记"来源标记标签"。该标记下的题目被排除在顺序/随机/专项练习与模拟考抽题池之外（`sampleQuestions` 与 `StartSequential` 统一 `NOT EXISTS` 过滤），标签不出现在学员端专项练习标签列表（`ListQuestionTags(activeOnly, includeSourceTags=false)`），`StartTagPractice` 对 source 标签直接拒绝。语义：真题题只能通过真题卷作答，保证积分门禁有意义；去重归并到存量行的真题题（未打标）留在公共池，属正常题库题。错题本重做按 question_id 直取，不受影响。
- **按套权益**：`sku = "real_paper:<paperID>"`、`ref_id = "<paperID>"`（语义同课程直兑 `course:<id>`）；`RedeemRealPaper` 单价读商城项 `unlock_real_paper`（缺省 300，管理员调价即全卷调价），事务写 `user_entitlement` + 负流水 + 扣分，重复兑换幂等报"已兑换"。旧泛 sku `unlock_real_paper`（`ref_id = sku`）保留 seed 兼容但前端不再调用。
- **权益门禁位置**：列表返回 `entitled/price` 供前端展示；练习/考试开始接口在后端强校验（未兑换拒绝）。进度保存与逐题提交不重复校验（拿不到题目即刷不了）。
- **前端**：真题列表保留 Variant C 年份时间线；已解锁卡片双入口「开始练习 / 模拟考试」，未解锁展示价格 + 兑换确认；新页 `RealExamPractice.vue`（`real-exam/practice/:paperId`，不进侧栏）复用 `usePracticeSession`；`MockExam.vue` 支持 `?paper=<id>` 进页即开考。列表数据 `credential_id` 由前端按当前证件注入，与 practice-stats 同口径。

## 备选

- **真题题留在公共池、仅隐藏标签选项**：拒绝，219 道真题在顺序/随机练习与模拟考免费可刷，300 积分/套的门禁形同虚设。
- **套卷独立判分流（`questionScoreByFlow` 加 `real_exam` 行）**：拒绝，导入题已带 score=3/4/2（与 practice/mock 分值表一致），`mockExamMaxScore` 的 `q.Score > 0` 路径自动生效，无新增分值语义。
- **卷题一对一（复制题目行）**：拒绝，同题跨卷重复存储、练习记录/错题本引用分裂。
- **把真题题从错题本排除**：拒绝，买卷练错进入错题本重做是学习闭环的一部分。

## 后果

- 新增 migration `000004_real_exam_paper`（两表 + `mock_exam.paper_id` + `question_tag.is_source_tag`）；`down` 对称回滚。
- 导入工具新增 `PaperQuestionRef` 计划结构与 `ApplyPapers`；对已导入库重跑 `-mode all -write` 即可补卷（幂等）。
- 学员端顺序/随机/专项练习与模拟考抽题池收窄（排除真题题），抽题规模影响约 219/8000。
- 真题卷考试记录进入模拟考历史（`paper_id` 可溯源），与随机模拟考共用清理 TTL。
