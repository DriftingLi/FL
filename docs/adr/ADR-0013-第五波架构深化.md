# ADR-0013: 第五波架构深化——dict 读面 / 分页 / 判分 / handler 装配 / 前端 module

- 状态：已接受（2026-08-14，architecture review 14 candidates + grilling 逐一定案）
- 领域：估值 dict 读面 / 主 service 分页与判分 / handler 装配根 / 前端 module 收敛

## 背景

第四波深化（ADR-0012）后，architecture review 并行 4 个探索 sub-agent 读码（估值 / 主 service / API 与横切 / 前端），产出 20 个 candidates，经 deletion test 与 grilling 去重聚类为 14 个 deepening candidates 并逐一定案。本 ADR 记录定案结论，作为未来架构评审的锚点，避免重新提议已决策事项。

## 决策

### 估值组

1. **dict 读面 descriptor 化（简单读引擎）**：22 个简单单表读（List/Get）的 SQL + scan 由 ReadSpec 生成、收进一个引擎；级联查询（9 个，JOIN/GROUP BY）与复杂查询（Find/Fuzzy/AlgoParams/SeriesConfigOptions）保留 typed。字段 Name/Column/Type 复用写面 dictcrud.Field 为单点（+ 自动补 id），读面独有的 SELECT 列顺序 / ORDER BY / WHERE 模板 / 缓存 key 由独立 ReadSpec 声明。typed 方法保留为薄 facade（方法名/签名/返回类型不变，内部调引擎），DictionaryReader interface 与 service 公式调用零改动。ReadSpec 放 repository 包（复用既有 repository 到 dictcrud 单向依赖）。

2. **缓存契约真单点**：读 key 全量收入 dictCacheContracts（补 dict:condition:list / dict:region:provinces / dict:vt:list 三处游离字面量）；新增静态测试扫描 repository 包禁 dict:* 字面量，未来新增读方法不声明进契约即测试失败；ListAlgorithmParameters 去外层缓存（消除嵌套复读与失效契约漏覆盖）。

3. **CoefficientResolver 合并**：定义单一 interface（Get + ReadFloat），CoefficientProvider 与 CoefficientSnapshot 都实现它；删 readWithFallback 包级函数，khours.go 4 次手写兜底改走 resolver，消除「读系数+兜底」4 形态漂移。

4. **测试门禁**：读面引擎加 shape-lock 测试（22 个方法返回 shape 与深化前字节级一致）；保留 ktime/khours/kcondition 等纯函数公式测试，内存 fake 补 ReadFloat。

### 主 service 组

5. **BuildDailySeries 单一函数**：抽 BuildDailySeries(days, byDay) 返回 {Days, Labels, Data, ActiveDays, Total}，把 days 钳制（7/30）、startOfDay 归零、起点、补 0 序列、activeDays、total 累加全藏进 implementation；student queryStudyStats 与 tutor GetGradingStats 只保留各自 SQL 聚合出 day 到 count 的 map。时区保持 beijingNow（Asia/Shanghai）。

6. **paging QueryWithScan**：pkg/paging 新增支持 Scan 到自定义行（join/多列 Select）的查询骨架；forum ListTopics / notification List / profile_review ListRequests 迁入，钳制上限差异（100/50/100）用 ClampMax 参数各自保留，不强行统一业务上限。

7. **gradeShortAnswer 原子入口**：把「评分 - 及格判定（score 不小于 maxScore*0.6）- 落库 IsCorrect - Save」收敛为一个 higher-level 判分入口；grading 三处（GradeAnswer/RegradeAnswer/ConfirmAIGrading）与 practice_mode 不再各自重推导及格线，shortAnswerPassRatio 语义只出现在一处。

8. **QuestionLoader 批量加载（带列选择）**：抽带列选择的批量题目加载器（题干/答案分离），loadOrderedQuestions 与其内部复用；消除 practice / wrong_question / grading / level_exam / student 列表循环内逐题 db.First 的 N+1。

### API/横切组

9. **HandlerAdapter（延伸 ADR-0009 struct 方法）**：在 struct 方法之上再收一层 Endpoint(parse, invoke, render) 抽象，吸收「atoi 解析 - BindJSON - 响应信封 - map 取字段」公共守卫链。struct 方法仍保留为 handler 声明形式，Endpoint 只吸收公共骨架，不重新引入闭包注册。顺带统一 queryIntPtr 语义（id 大于 0 守卫单点）。

10. **AuditSvc 下沉**：写（db.Create）+ describeAuditAction 命名 + 分页读收进 internal/service 的 AuditSvc；middleware.AuditLog 收 AuditSvc + logger（不再收裸 db/cfg），AuditHandler 收 AuditSvc，读侧 List 走 paging。审计 model 与命名不再跨 middleware/api 两包。

11. **VditorUpload adapter 函数**：抽 Vditor 上传适配器（File 读取 - ValidateImageFile - SaveFile - Vditor 信封响应），tutor.go 与 featured.go 两份 UploadImage 只传保存目录 + 可选 hook，信封协议单点。

12. **RouterDeps 聚合横切（微调 ADR-0009 按需注入）**：抽小 RouterDeps struct（Session/DB/Logger 等横切依赖），Register*Routes 收 RouterDeps + 按需业务 service，替代 22 处重复收 sess；业务 service 仍按需注入、不吞整个 Deps；删死字段 AISvc。

### 前端组

13. **useRoleDashboard**：收敛 student/tutor 两页 Dashboard 的同构骨架（banner + QuickCard 三列 + time-series 统计 section + 时间 tab + ECharts option）为单一 composable，interface { statsFetcher, cardMappers, seriesType, bannerConfig }；admin Dashboard 不纳入（stat-cards + bar/pie 不同构，硬塞会膨胀 interface）。

14. **useExamSession**：抽 useExamSession({ enter, save, submit }) composable，藏会话状态（inExam/remainingTime/currentIdx/shellRef）+ 顺序约束（submit 前先 save）+ reset；MockExam/LevelExam 只注入三个持久化 adapter（ADR-0010 后端 answering_session 的前端对称收敛）。

15. **课程 DTO 单一契约**：CourseSummary/CourseChapter 为唯一事实源，TutorCourse/TutorChapter/CatalogCourseNode 用 Pick/Omit/& 派生；去掉 [key:string]:unknown 兜底，让类型检查捕捉字段漂移（admin.ts 的 AdminCourseItem 已是 prior art）。

## 约束

- 全部响应 shape 零漂移（dict 读面 shape-lock、paging/判分既有契约不变）。
- dict 读面 typed facade 保留，DictionaryReader interface 与 service 公式调用零改动。
- 各候选既有行为冻结：时区、钳制上限、及格线 0.6、Vditor 信封、审计记录 schema 均不变。
- 三张会话表结构与前端契约不变（延续 ADR-0010/0012）。

## 后果

- dict 读面从 34 个散落方法变为「一份 ReadSpec 描述符 + 一个引擎 + 静态测试」，字段真值单点，scan 顺序/列名漂移无法复现。
- 分页/判分/参数解析/上传/审计的复制回归无法复现；N+1 由 O(N) 查询收敛为 O(1) 批量。
- ADR-0009 两处调整：(a) 候选 9 在 struct 方法之上加 Endpoint 抽象（延伸而非反转）；(b) 候选 12 用 RouterDeps 聚合横切依赖、业务 service 仍按需（微调而非反转）。未来评审不再把「handler 样板重复」与「sess 重复传参」当作新 friction 提交。
- 测试策略：shape-lock 门禁 + 纯函数公式测试保留 + resolver/adapter 的 in-memory fake 补 ReadFloat。
