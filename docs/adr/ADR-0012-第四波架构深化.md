# ADR-0012: 第四波架构深化——课程列表/报告协调器/登录与验证码收尾

- 状态：已接受（2026-08-13，architecture review 7 candidates 全量）
- 领域：课程目录 / 残值评估报告 / 账号与认证 / 前端 module 收敛

## 背景

前三波深化（ADR-0009/0010/0011）后，architecture review 扫描最近 60 次提交的 hot spots，发现 7 个 deepening candidates：前端课程中心筛选三页字节级复制（#165 计数联动修复需手工同步两份）、导师课程列表绕过挂载不变式且 N+1、发送验证码交互四份副本、验证码登录未并入登录骨架、报告协调器 Generate 无并发守卫且旧记录建议 fallback 不对称、用户身份字段前端双份手写 shape、Kt_adj 公式前端 TS 复刻。

## 决策

### 1. 课程中心筛选 module（前端）

- 新增 `useCourseCatalog` composable：facets/countOf/totalAll/select/fetchCatalog 为 interface，双向计数、目录树装载（levels 从树派生，省一次请求）、封面渐变全部吸收进 implementation；
- 学员端/导师端/管理端三页退化为薄 adapter；管理端扁平列表口径以 data-source adapter 形式纳入同一 module；
- FacetCard/CourseCard 共享组件吸收三页重复 CSS 与渐变。

### 2. 导师课程可见性口径变更（行为变更）

- 导师「我的课程」并入 courseList module 并采用 onlyMounted=true：未挂方向/等级的课程对导师隐藏，与学员端口径统一；
- courseListOptions 升格为 module interface；`fillChapterCount`/`fillPrereqIDs`/学员数批量回填，消除 N+1；删 tutorID 死参数。

### 3. 发送验证码交互 module（前端 useSendCode）

- interface：`send(target, channel)` + 构造期 purpose（login/register/bind/account_change）；
- 邮箱正则与后端 net/mail 语义对齐；账号正则统一 4-20 位（对齐 IsValidAccount）；
- 两处 `/auth/me`（主站+估值）对 `email_` 前缀手机号源头过滤为空串，前端 displayPhone 删除。

### 4. 用户资料 typed module（前端）

- 单一 UserProfile interface（删 `name` 与 `[key: string]: any`）；派生 `displayName = username || account`；四处 Dashboard 回退链与 `as any` 读取清理。

### 5. 登录骨架延伸与验证码语义修复

- `LoginWithCode`/`RegisterWithCode` 并入 `verifyAndIssue` 骨架（禁用校验/签发/结果组装只维护一份），估值 `ValuationAuthHandler.Login` 死端点删除；
- `ChangeAccount` 成功后响应带新 token（加性变更），前端替换本地存储——JWT claim 不再陈旧；
- `Verify` 失败尝试不再重写完整 TTL（错误输入不得延长验证码有效期）。

### 6. 报告协调器并发语义与 fallback 收敛

- Generate 与 DownloadURL 共用单一 guarded 入口（key 空间 `report:<id>`）：POST 强制重生成、GET 缺失才生成，均在 singleflight 内；上传 key 改 UnixNano 消除同秒碰撞；
- 旧记录建议 fallback 收敛为 service 层单入口（建议为空才填充，保 ADR-0004 事实锁定）；电池用记录内 health/SOH，缺失才默认 1.0；EvaluationHandler.Get 详情与 PDF 口径一致。

### 7. 估值管理端写操作接入审计

- `/api/valuation/admin/*` 写操作接入 AuditLog 中间件，与主系统管理端同一留痕口径。

### 8. 未来价值曲线锚点 decay_anchor

- 评估结果（创建响应与详情）新增 `decay_anchor` 字段（加性变更，评估时点锁定）：后端持有 Kt_adj/λ 公式唯一实现，前端 FutureValueChart 退化为 d^n 乘法渲染。

### 9. 契约基线

- 全部响应 shape 零漂移（shape-lock 测试门禁）；允许的死字段清理（category 残留）；值级/加性变更仅限 email_ 过滤、account_change 加 token、decay_anchor 三处。

## 后果

- 课程中心筛选/发送验证码/身份字段的复制回归（如 #165 类双份手工同步）无法复现；
- 导师端可见性变更可能影响现有导师感知：未挂方向/等级的课程不再出现在其列表（管理端全量列表不受影响）；
- 报告协调器并发 POST 同 ID 由并行互覆变为排队合并，语义更合理；
- 验证码错误输入不再延长有效期，严格 5 分钟 TTL 生效。
