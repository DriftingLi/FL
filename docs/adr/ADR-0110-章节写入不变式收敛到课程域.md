# ADR-0110：章节写入不变式收敛到课程域

- 状态：已接受
- 日期：2026-11-27
- 领域：Web 讲师工作区 / 课程与章节 / 文件上传

## 背景

章节正文、附件、换挂与提审都已执行课程认领谓词，但 Markdown 图片上传只经过 `course.author` 能力守卫，未校验章节所属课程的认领。图片上传落盘后还可能继续写附件行或草稿标记，失败时遗留孤儿对象。能力键与数据级不变式因此在不同的 handler 里被重新解释。

## 决策

1. **章节写入 module 的 seam 放在 `course` 域**。它拥有认领、章节归属、内容性质、草稿降级与审核快照；`tutor` 与 `tutorfile` 只作为 caller 或 adapter。
2. **正文、图片、附件、换挂与提审穿过同一写入 seam**。`course.author` 仍只回答“能否使用讲师写面”，不替代章节编辑权。
3. **讲师图片上传强制有效 `chapter_id`**。无 ID、章节不存在或未认领均拒绝，不再提供根目录降级。
4. **module 拥有落盘补偿**。存储对象落盘后若 DB 事务失败，由 module 删除已落盘对象；caller 不承担内部清理。

## 后果

- 新增章节写路径不需要重新学习认领、归属、草稿与补偿规则，locality 提升。
- HTTP 契约测试可直接覆盖真实 seam：伪造他人 `chapter_id` 必须拒绝，认领后成功，DB 失败必须清理存储。
- 前端章节编辑会话保持独立，不并入本 module；见 `CONTEXT.md`“章节编辑会话”。
