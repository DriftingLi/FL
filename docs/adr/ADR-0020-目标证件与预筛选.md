# ADR-0020: 目标证件（Target Credential）作为培训域顶层分区与预筛选

- 状态：已接受（2026-08-24）
- 领域：培训域 / 课程与题库分区、学员上下文

## 背景

培训域既有 `specialty → level → course` 三层虚拟目录与 `question_tag` 题库标签，但缺乏"学员想考什么证"的顶层分区。新增两类持证目标——特种作业上岗证（叉车司机N1/低压电工/焊工等）与工程机械维修工·叉车维修方向（L5-L1 五级递进）——每证需拥有独立的课程库与题库，且学员在首次注册/登录时即需选定目标证件，后续在侧栏顶部可切换。管理端与导师端需同步感知该分区。

## 决策

- 引入 **目标证件（target credential）** 为培训域新的顶层分区实体（`credential` 表：`code` 唯一、`category`=`special_operation|skill_level`、`level` 仅维修工类填 5-1、`sort_order/status/description`），与既有"证书模板（培训合格证书）"严格区分。
- **单归属直挂**：`course.credential_id` 与 `question.credential_id` 必填外键（V1 1:N，预留 M:N 共享扩展），查询层以 `credential_id = current_credential_id` 为分区谓词；`specialty/level/tag` 退为证件内的二级分类，保留全局共享但在证件内二次过滤。
- **单选当前证件**：`hrwai_users.current_credential_id` 存单值；存量与新用户 `NULL` 时在 `router.beforeEach` 强制拦截至 onboarding 选证页（`GET /api/credentials` 分组返回，`PATCH /api/me/credential` 切换），**不提供跳过**。切换即全局过滤器，侧栏顶部 `CredentialSwitcher` 分组下拉承载。
- **过滤边界**：按证件隔离 `course/chapter/question`（含练习/模考/错题/搜索/收藏的 course/question 分区）；不隔离论坛/AI/资料审核。**占位证件**（0 课/0 题）可选，视图呈"内容建设中"空状态。
- **迁移与管理**：migration 种子 8 行（N1/低压/焊工 + L5-L1），存量课程/题目一键归 `forklift_n1`；V1 即交付 `admin/credentials` CRUD，课程/题目创建/编辑表单新增"所属证件"必选，导师端"我的课程/题库管理"同步改造；历史学习数据（`study_record/wrong_question/practice_progress/mock_exam`）按所属 `credential_id` 自然隔离，切换仅改视图不丢数据，仪表盘支持"当前证件/全部证件"双口径。

## 备选

- **映射而非直挂**：用 specialty/level/tag 组合映射证件。拒绝：规则复杂、无法表达"某证专属课"，且与"每证件独立题库"直觉相悖；直挂最简单，未来需复用时再加中间表演进为 M:N 成本低。
- **多选并存**：允许同时勾多证。拒绝：与"侧栏顶部单选切换即全局过滤器"的交互冲突，且增加所有查询的 `IN (...)` 复杂度。
- **占位不可选/可跳过**：拒绝：与"强制预筛选"目标矛盾，用户只能选 N1 时强制流程形同虚设；可选+空状态更自洽。
- **切换清数据**：拒绝：用户可能多证并考，丢数据不可逆；视图过滤保留全量履历更符合预期。

## 后果

- 后端新增 `credential` 模型与 `CredentialService`/`CredentialHandler`，所有课程/题目读路径追加 `credential_id` 谓词，写路径校验必填；搜索/收藏/错题/模考/统计等下游需同步感知分区。
- 前端新增 `CredentialStore` + `CredentialSwitcher`（仅 `TrainingLayout` 开启）+ `onboarding/credential` 拦截路由；`CourseCatalog/QuestionManage` 等表单追加证件选择器。
- 迁移后 `course.credential_id` / `question.credential_id` 非空约束与索引；占位证件的空列表需统一空状态与文案。
