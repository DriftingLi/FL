# ADR-0038: 剩余控件观感治理口径

- 状态：已接受（2026-09-10）
- 关联：#766（spec）、#773/#774（expand）、#775/#776（migrate）、#777（contract）
- 前置：ADR-0035（UI 控件收敛到 ui/ 封装层）、ADR-0037（el-table 观感治理）

## 背景

ui/ 封装层在 #716/#718 等批次后仍余 6 类 EP 控件未治理：el-tag 78 / el-tooltip 16 /
el-checkbox 12（含 group 2）/ el-switch 9 / el-radio-group 8 / el-upload 6。浏览器实测
（生产 CSS + EP 真实 DOM + Chromium getComputedStyle）发现两个真实观感缺陷，其余颜色
体系已正确跟随主题。

## 决策

### 1. 薄封装 + attrs 透传，不做受控 API

六个组件（UiTag / UiSwitch / UiCheckbox / UiCheckboxGroup / UiRadioGroup / UiTooltip /
UiUpload）统一模式：`inheritAttrs: false` + `v-bind="$attrs"` + 动态 slot 转发 +
转发式 defineModel。**不设项目默认值** —— 封装后默认行为与原 el-* 完全一致，迁移零
行为变化。理由与 UiTable 拒绝封装同理的反面：这六类的用法差异在属性透传而非容器，
薄封装即可承接；强受控 API 会逼业务页重写属性。

### 2. UiTag 例外：tone 语义 API 为全站唯一标签入口

UiTag 先于本批存在（受控 API：tone/size/effect，论坛域 7 处存量）。经决策**不另建
type 直通薄封装**，而是扩展 tone（加 primary/info 直通）、size 兼容 EP 原值
（small/default/large 与旧值 sm/md 并存）、attrs 显式透传，并导出 `UiTagTone` 类型供
调用方映射表收窄。el-tag 迁移时 `type="success"` 改写为 `tone="success"`，动态绑定
`:type="expr"` 改 `:tone="expr"`。EP 空串 type 语义（= 默认 primary）一律显式写
`'primary'`，不允许 `''` 进 tone。

### 3. 观感缺陷走全局 CSS，不走封装内修

两个深色缺陷均修在既有的 element-overrides.css 变量层（ADR-0037 已确立的 seam）：

- `--el-border-color-darker` 映射到 `--color-border-dark`（EP 出厂 #cdd0d6 固定值
  导致 upload picture-card 边框不随主题翻转；此项也是全站该变量的唯一未映射档）
- `[data-theme="dark"] .el-popper.is-dark` 覆写（EP 出厂把气泡底色绑在
  `var(--el-text-color-primary)` 做反色，深色下翻成浅底深字）：底色改 `--color-bg-card`、
  文字用深色下的 text-primary（= 浅色）、边框与箭头跟随；**浅色保持出厂反色不动**
  （深底白字本就正确）。实测深色下 tooltip 底 #F1F5F9→#1E293B、upload 边框 #cdd0d6→#475569。

理由：封装不会自动修 popper/upload 的底层样式；全局层一处修复，tooltip 16 / popover
dark 2 / upload 6 与未来新增用法一并受益。

### 4. radio 项保持原生

`el-radio`（8 处）与 `el-radio-button`（7 处）不封装：它们是 group 的「内容项」而非
「容器」，必须嵌在 radio-group 内使用，观感由全局变量层保证。checkbox 同理 —— 组
（el-checkbox-group 2 处）收敛到 UiCheckboxGroup，组内子项保持原生。

### 5. 已知 flaky 的根治路径

CourseCatalog.spec.ts 连续超时的真因是 29 个 spec 全量挂载 ElementPlus，import 累计
310s，CI 2 核 runner 并发争抢 —— 与本 ADR 同期由 #765 的 epLite（测试专用按需注册）
根治，见 ADR 同目录的测试基建约定（AGENTS.md「测试」词条）。

## 后果

- 全站业务页六类控件裸用清零（残留仅在 components/ui/ 封装层自身）
- el-tag 迁移后调用方使用 `tone` 而非 `type`；新增标签一律 `tone`
- 后续若 EP 升级调整子组件导出结构，epLite 与 UiTag 的映射表需同步（均已注释标注）
