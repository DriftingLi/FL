# ADR-0014: 认证页前端收敛与视觉统一（AuthPageShell / useAuthFlow）

- 状态：已接受（2026-08-15，架构深化第六波 波2 spec #208）
- 领域：账号与认证 —— 登录 / 注册 / 找回密码（前端 module 收敛）

## 背景

auth 三页（Login 671 行 / Register 580 行 / ForgotPassword 488 行）458 行逐字节相同、约 400 行重复 CSS；安全敏感的 redirect 回跳策略 isSafeRedirect 内联在 handleLogin 闭包中不可测试；validate.ts 的 confirmPasswordRule 是无人引用的死代码；「四段 radio tab」的登录方式切换形态被产品判为不佳。该形态与 ADR-0012 §1 已消灭的「课程中心筛选三页字节级复制」同构。

## 决策

### 1. 认证页外壳（AuthPageShell）+ 视觉统一

- 三页共用 AuthPageShell 组件（背景/卡片/方式切换/验证码行/按钮/footer 唯一实现）；字段模板保留各页声明（不做 schema 化表单引擎，YAGNI）。
- 切换形态：**主次分离**——首屏密码主表单 +「或使用以下方式登录」分隔线下的图标按钮（邮箱/手机/微信，active 高亮，微信沿用生态绿 #07C160）；点击图标整块切换视图，视图顶部「返回」。
- 底色：**白底极简**（纯白背景、1px #E2E8F0 细边框卡片、单一品牌蓝 #2563EB）；角色 badge 三色保留（学员蓝/导师青/管理紫）。
- tutor/admin 角色不显示次要方式按钮与分隔线（仅密码入口，行为不变）；微信占位以图标按钮保留（点击提示暂未开放）。
- 视觉方案经 mockup 提案（v2 方案 D）逐套交互确认后定稿。

### 2. useAuthFlow 状态机

- 三页提交编排（mode 状态、validate→submit→afterSuccess 顺序约束、loading、错误处理）收敛为 useAuthFlow；页面注入 submit 与 afterSuccess adapter；wechat 未开放以 submit 返回 false 阻断后续。
- 顺序约束单一实现：validate 失败不调 submit、submit 异常不调 afterSuccess、finally 复位 loading。

### 3. isSafeRedirect 与路径↔身份知识单点

- isSafeRedirect(role, target) 抽为纯函数（utils/authRedirect.ts）；「路径前缀→允许身份」表（/training/tutor→tutor、/admin→admin、/training|/valuation|/ai-assistant→hrwai_user，按前缀长度降序）单点，getTargetSubdomainForPath 与 isSafeRedirect 同表派生。
- resolveWorkspaceForRole 单点，router 4 处角色 redirect 与守卫改调；登录页判定改用 route meta 标记（authPage），路径/名字枚举删除。

### 4. confirmPasswordRule 激活

- 注册/找回密码两页内联「两次密码一致」校验器删除，validate.ts 的 confirmPasswordRule 激活（空值文案参数化：请再次输入密码 / 请再次输入新密码）。

### 5. 同波前端 module 收敛（并列记录）

- usePracticeSession（练习会话状态机，QuestionBank 560→380 行薄页面）；
- useVerifyDialog（验证码对话框状态机，Profile 三对话框配置化）；
- useStudyTracker（学习时长上报，游标判定语义化消除 detail===null 脆弱耦合）；
- 导航与页面跳转收敛为 route name（NavItem.routeName + 高亮由 route 表派生）。

## 约束

- 全部路由/导航/跳转/提交流程行为零变化（含 valuation 子域名回跳与 /dashboard/* 特判）；
- 练习断点续传三态、学习计时 60s 阈值与 ceil 取整行为逐秒等价；
- 响应契约零漂移；本波无后端改动。

## 后果

- auth 三页复制回归无法复现；新增登录方式（如真实微信接入）以 altModes 增量接入，零样板。
- 未来评审不再把「auth 三页复制」「四段 tab 切换形态」「isSafeRedirect 内联不可测」当作新 friction 提交。
- 已知环境负债：本波新增前端 spec 因沙箱 esbuild spawn 限制未在本地执行 vitest（CI 亦不跑 vitest），待环境修复后补跑（见 PR #235 说明）。
