# ADR-0059: 第十二波架构深化（登出单点 / 内容对象表 / 残值两档 / 附件归属 / 论坛错误语义 / 题库 typed 写面）

- 状态：已接受（2026-09-19，#1168 六票统一立波；后端 PR 先合、前端 PR 后合）｜领域：会话终止 / 种类派生表 / 列表档位 / 附件判据 / 错误码 / 审核状态机

## 背景

六处同型摩擦：登出编排四份互不一致（侧栏漏 revoke）；搜索/收藏的「种类→称谓/色/落点」手抄表三周六张票修它；残值配置用档位守卫射程外的第三份实现、读失败渲染成空表；「附件是否本站」判据五份写法、精选与简历写面无门禁；论坛把不存在/无资格/库故障一律 400、裸错误串当文案；讲师改已发布题未经审核即进题库池，写面 status 通道可直置 published 绕审核。

## 决策

1. **登出单点**：auth store 具名 `signOut()`（revoke→清本地→返回结果；本地清除无条件）；confirm、落点、本页清理留调用方，四界面退化为 adapter。
2. **内容对象表**：「内容对象」声明表（五类 × 称谓/标签色/落点/可检索/可收藏/进 tab 六槽，三行为槽互独立、不由称谓反推），搜索页与收藏页全派生；落点=路由名+参数且必填，种类枚举与后端契约做穷尽互等锁。
3. **残值两档**：原价表 tab→`useAdminTable`，算法参数区→`useAsyncPage`（只收装载错误通道，保存侧留 `useDirtyDraft`）；删 `useCrudTable`；档位守卫扫描面扩到 `composables/`。
4. **附件归属**：单 module 收前缀登记+本站判定+URL→key+multipart 读取；featured 补门禁；简历写时校验、**编辑未改不动**（存量外链放行）。
5. **论坛错误语义**：哨兵三族（存在性→404/所有权→403/前置→400），域表无 fallback ⇒ DB 故障 500；GetTopic 两处手写映射登记为渲染定制例外；前端 toast 改用后端 message、列表判据区分业务 404 与空列表。
6. **题库 typed 写面**：typed 入参拒收 status，迁移只认显式动作（先补 `POST /questions/:id/submit`，前端改接后关通道删旁路）；不变式：讲师改内容与计分字段→回 pending，分区属性不动状态，管理员即时生效。

## 理由

六条同为「判据/派生收进一处、消费面退化为 adapter」；附件判定与悬空回收是既有接缝（第二消费者已在）。行为变更只有错误码改码与写面拒 status，已核实兼容：三端 toast-only，移动端信封 message 在即不破；SSE 字节、ADR-0021 分值表、ADR-0049/0050/0058 题库池口径不触碰。

## 被否备选

只补漏掉的 revoke / 在两页各补判据表（不封第 N+1 份抄写，票2 动机正是三周六张票）；论坛只改文案不改码（「不存在」仍与「库故障」不可区分）；题库保留 status 通道 + 校验拦截（旁路无人使用，状态机不应靠实现巧合）。

## 锁

后端：`attachment_test.go` 判据表驱动 + `attachment_gate_test.go` 门禁行为 + `forumErrStatus` 快照（32 条）+ 37 处论坛契约同步 + `question_write_contract_test.go`（拒 status/submit/不变式）+ `TestQuestionContentTouched` + 路由数 329。前端（配套 PR）：store spec「必 revoke、失败也清」、内容对象表互等锁、档位守卫扩展 + 两档既有 spec。
