# ADR-0075: 回落出口的子域身份不变式

- 状态：Accepted
- 日期：2026-10-10
- 关联：#1651（缺陷）；#1614 / ADR-0071（专属子域身份先行裁定）；#618 / ADR-0047（守卫决策管线）；#1363 / ADR-0067（refresh 令牌父域 Cookie）

## 背景

#1615 落地后 mentor./manage. 已正常（不符角色清登录态停本子域登录页），但该裁定只覆盖了**专属子域**。父域 Cookie 同样让讲师/管理员登录态在共号子域（training./recruit.）生效，而共号子域沿用旧行为：角色不符 → `workspaceFallback`「送回你的工作台」→ `subdomainBoundaryStep` 升级成整页跳转：

- 讲师 Cookie 开 `training.` `/` → `resolveWorkspaceForRole('tutor')` = `/training/tutor` → 边界 external `mentor.`；开 `recruit.` → roleStep 拒 → 回落 `/training/tutor` → 同样弹 `mentor.`
- 管理员 Cookie → `/admin/dashboard` → 弹 `manage.`

线上四子域同一 bundle（index-B_L82QIA.js），部署滞后排除；这是 #1614 的镜像（当时是学员被弹去 training.，现在是讲师/管理员被弹去 mentor./manage.）。为何现在才显形：ADR-0067 之前 tutor/admin 在共号子域的 localStorage 为空（匿名 → 停登录页不触发回落），Cookie 恢复后该老路径 100% 触发。

## 决策

**不变式：回落决策凡把用户送向当前子域之外，或原地自绕，就地改为清登录态回本子域登录页。**`workspaceFallback` 出口两道闸：

1. **身份落点异域**：目标落点子域 ≠ 当前子域，或 admin/tutor 的**静态落点**子域 ≠ 当前子域（他们在共号子域上本就是「别人」，落点再同域也是替别人选的路）→ `clearAuth` 回本子域 `/login?redirect=`；
2. **共号子域自绕**：recruiter/未知角色的回落落点 `/training` 恰为当前路径时，重跑守卫会得到同一决策（vue-router 掐成空白页）→ 同样清态回登录页。

配套两处：

1. **`/` 根路径 redirect**：子域名已知（非 main）一律按**子域假想角色**落点（`getDefaultWorkspaceBySubdomain()`），不再按实际登录角色选工作区；IP 直连走原角色分支；
2. **Login 成功身份门**（`afterSuccess`）：登录身份 ≠ 子域缺席角色 → 不落地、就地清态提示换号。不挡这一拍的话，随后的 `router.push` 会被回落不变式清态打回本页，形成登录循环。

## 理由

- **为什么在回落出口而不是再加一个前置步骤**：#1615 的 `subdomainRoleStep` 管的是「专属子域上不该进门的人」；本缺陷发生在**进门之后的出路**（角色/能力校验拒了之后往哪送）。两道闸都在出口上，一处改动覆盖 roleStep 与 capabilityStep 两条路径，也不与能力装载（4b load-capabilities）的时序纠缠。
- **为什么判落点子域而不是角色清单**：子域归属单点在 `WORKSPACE_SUBDOMAIN`（路由 meta.workspace 派生），与边界步骤同一套事实源；按角色写清单会在加角色时漂移。
- **admin 未落定能力集时多一次补拉**：4b 先行（#1645 的设计承诺），补拉后**重跑**才命中出口①清态。一次冗余请求换时序不变，可接受。
- **深链接交接不受影响**：带 `auth_token` 的跨子域跳转是用户显式点「去另一端」产生的（届时 URL 已在目标子域、路径属该子域），回落不变式不触发。

## 后果

- 讲师/管理员 Cookie 开 `training.`/`recruit.`：清登录态 → 停该子域登录页（可换学员/企业号），不再被弹去 mentor./manage.；
- recruiter/未知角色直接开 `training.` 根路径：停登录页（原为空白页死循环）；
- mentor./manage. 行为与 #1615 一致（学员/跨角色停本子域登录页）；
- IP 直连部署形态与 main 子域：完全旁路，角色/能力回落语义照旧（单测钉死两侧）；
- 登录页输错端的账号：就地报「该账号不属于此端」，不再登录循环。
