# 行为事实的证件分区在写入时冻结

「当前证件」是学员侧的单选上下文，切换即全局过滤器（`CONTEXT.md`「当前证件」词条）。但**分区值从哪来**，仓里一直有两套做法并存：

- `practice_progress`（#414 / 迁移 000013）与 `mock_exam`（#1005 / 迁移 000032）把证件**落进记录**：那次进度 / 那张卷子属于哪个证件，在**产生那一刻**定下来；
- `question_practice_record`（练习记录）没有分区列，它的三个读面各走各的：`practice-stats` 读时 `JOIN question` 按**题目当前归属**过滤，`/practice-mode/history` 与 legacy `/practice-mode/stats` 完全不分区。

后果在生产上是可测的：某学员（当前证件=低压电工）有 15 条练习记录、全部落在别的证件下 —— 可达的「数据报告」页顶部总览（`practice-stats`）报 **0**，下方 by_type 明细（`/stats`）报 **15**，**同一页两个数字互相矛盾**。

## 决定

**学员行为事实的证件分区在写入时冻结**：练习记录 / 练习进度 / 模考记录在产生那一刻记下**当时的当前证件**；此后切换证件、修改题目归属都不回溯改写历史归属。读面按记录上的分区过滤，`nil` = 不分区（未选证件时看全部，与题库池 / 错题本的既有 nil 语义一致）。

- `question_practice_record` 加 `credential_id`（迁移 000033）：练习提交与错题重做写入它；
- 三个读面统一按它过滤：`/practice-mode/history`、`/practice-mode/practice-stats`（退役 `JOIN question`）、legacy `/practice-mode/stats`；
- **个人流水面不按证件分区**：积分流水 / 打卡 / 任务中心 / 个人动态（`credentialScope` 登记表里的 4 处 opt-out，理由各自写在表里）；
- 全局读面保持全局：`points` 的「今日刷题」计数（积分按用户全局，ADR-0034）、单题全站正确率（不是个人读面）。

## 理由与权衡

**为什么冻结、而不是读时归属**：分区描述的是「**这件事发生在哪个证件下**」，是事实；题目归属是**内容治理状态**。今天题目归属事实上写一次就固定（导师改题路径不含 `credential_id`、导入工具按「证件+题干哈希」匹配而不迁移归属），所以读时 JOIN 现在能用 —— 但一旦归属可改，同一份历史就会**昨天属于 A、今天属于 B**，统计与列表一起搬家。冻结让「历史是事实」只有一个落点，也让三张行为表口径一致。

**为什么练习历史属于内容读面、不属流水面**：`CONTEXT.md`「当前证件」词条已把「练习」列入分区族。积分 / 打卡 / 任务 / 动态不分区，是因为它们描述**账号行为**（与学什么证无关）；练习记录描述的是**学什么**。

**认下的代价**：切到「没练过的证件」时练习历史为空（生产实例：15 条 → 0）。这是诚实的空态、不是数据丢失；缓解靠空态文案（移动端接线票，另开）。

## Consequences

- 迁移 000033：加列 + 按题目反推回填（存量 22 行、**0 条落在未分区题目上**，故无需兜底分支）+ `(student_id, credential_id, created_at DESC)` 索引；回填收在函数里保留，供 pg 契约测试重放（照 000032 形状）。
- 错题重做路径顺带补上证件上下文：取题按当前证件校验，避免绕过错题本列表直调别的证件的题（该路由此前连证件形参都没有）。**有意不施加完整池 scope**（published / 排真题）—— 错题本是「我曾经做错的题」的历史面，题目下架或改标后若在这里被拦，列表会出现点不动的死链；那是错题本读面 scope 的独立议题。
- 口径对账成为可机械守卫的不变式：同证件下 `practice-stats.total_count == history.total`（本次缺陷的形态正是 0 ≠ 15）。
- 遗留、不在本 ADR 范围：Web 无练习历史消费点（`practiceHistory` API 皮是死路径，保留作契约镜像）；移动端「练习记录」页已实现且在 `pages.json` 注册但**无入口**，接线另票（归移动端负责人）。

## Considered Options

- **读时 JOIN `question.credential_id`**（`practice-stats` 现状）：零 schema 变更、今天 100% 可用。拒绝 —— 与 `practice_progress` / `mock_exam` 已立的写时冻结相反，仓里会出现两种「分区是什么」的定义。
- **练习历史当个人流水**（不分区、每行标证件）：与积分流水 / 打卡 / 任务中心 / 个人动态同族。拒绝 —— `CONTEXT.md` 已把练习列入分区族；且它与同屏渲染的 `practice-stats`（分区）会长期自相矛盾。
- **写时冻结 + 读面 JOIN 兜底未回填行**：拒绝 —— 两套口径并存正是要消除的东西；现网 0 条未分区题目记录，兜底没有对象。
