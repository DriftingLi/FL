# ADR-0092：树身份——目录为入口、登记分支为身份

- 状态：Accepted（2026-11-04）；取代 #2174 引入的「按 `feat/<票号>` 认树」判据
- 日期：2026-11-04
- 领域：工程协作 / 收尾机制（dev-close 第 8 步）
- 票：spec #2233 · 实施 #2247 / #2251 / #2253 / #2255；判据物 = `scripts/lib/dev-close.mjs`（`resolveTree`）、`scripts/dev-close.test.mjs`、`scripts/dev-close.ps1`

## 背景
旧判据按分支 `refs/heads/feat/<票号>` 认树，动机写在 `findTargetTree` 注释里：**目录可被改名，分支不会**。前提是分支名恒等于 `feat/<票号>`，而开工闸门 `new-worktree.ps1` 一直支持 `-Branch fix/… docs/…`。血账（2026-11-03 现测）：树 `wt-2230` 挂 `fix/2230-dead-subtab`、`wt-2189` 挂 `fix/2189-lint-brace-expansion` ⇒ 旧判据一律判 `tree=absent`，拆树与分支残留核对**静默跳过**，dry-run 照出一行「无待办」被读成已达成——失败长得像成功。

## 决策
**入口 = `git worktree list` 注册表里路径名为 `wt-<票号>` 的条目；身份 = 该条目实际登记的分支。** 目录名由闸门在创建处锁死、分支形态开放；PR 状态、未合并对账、拆树透传、分支残留核对一律消费身份分支。detached 条目（如 `wtx-base`）不参与票号判定；显式 `-Branch` 与身份不一致判红 `branch-mismatch`，不猜、不二选一。

## 被否备选
- **保留分支判据、只把写死处改成枚举候选**——`fix/*` `docs/*` `chore/*` 无封闭集合，枚举永远漏下一个。
- **按目录存在即认、不核登记分支**——目录在而分支属别票（改名、复用）时会**误拆别人的树**，比漏拆更坏。

## 后果
`tree=absent`（真不存在）与 `tree-branch-mismatch`（目录在、判据没匹配）从读数上分开，后者判红；`unregistered-tree` 指回 `-PruneOrphans` 不接管；`verdict=noop` 表「本次无动作」，`ok` 只留给真执行且对账通过的一腿。成本：认树多一次注册表解析，`wt-<票号>` 目录名成为硬约定。

## 实测
`wt-2189` 旧判据 `tree=absent … verdict=planned`；新判据 `TREE_RESOLVE state=registered … branch=fix/2189-lint-brace-expansion`，执行腿 `tree=removed … dir=ok reg=ok local_branch=removed … verdict=ok`，`git worktree list` 与 `git branch --list` 对账为空（#2253）。

## 回退腿退役判据
过渡期保留「主判据落空时按 `refs/heads/feat/<票号>` 匹配一次」的回退腿（命中打 WARN `legacy-branch-match`、不判红）；**连续一个修订周期零回退命中**即退役，收紧为纯目录判据并删除该腿与其用例。
