# ADR-0021: 真题练习占位与套卷模型

- 状态：已接受（2026-08-26）
- 领域：培训域 / 题库练习与真题套卷、侧栏导航与课程筛选（关联 #326）

## 背景

题库练习（`QuestionBank.vue` + `usePracticeSession`）已有顺序/随机/专项/标签 4 模式 + 模拟考试卡片，需新增“真题练习”二级列表占位（暂无数据），后续演进为套卷模型与答题链路。同时需落地练习统计（新增指标与接口）、课程热门/精品一级 Tab 与管理端标记、学员/管理侧栏二级分组（见 Spec #326 与 frozen plan）。

## 决策

- **入口与路由**：`QuestionBank.vue` 增加第 6 卡片“真题练习”（文案“历年真题套卷（占位）”）`→ router.push({ name: 'RealExamPapers' })` `→ 独立二级页 `training/real-exam`（扁平，与 `training/mock-exam` 并列），不复用 `usePracticeSession.mode` 状态机；侧栏中真题为 `question-bank` 的 `children` 子项（`config/navigation.ts:59`），`AppSidebar` 小幅适配（父高亮/折叠 tooltip/移动端 accordion，`TrainingLayout` 章节覆盖不变）。
- **占位期粒度**：仅列表占位（空态“真题建设中，敬请期待”+ 不可点假卡片/`ElMessage.info('功能建设中')`），不做答题壳与假题跑通，后端 0 依赖；真实数据后续按 `current_credential_id` 分区拉取。
- **套卷字段（初版 schema，7 字段与后续 `real_exam_paper` 一致）**：年份 / 套卷标题 / 题数 / 考试时长 / 所属证件标签（`credential_id` 必填，按 `currentCredential` 过滤，空态复用“内容建设中”口径）+ 来源 + 难度（复用 `course_level` 入门/进阶/专项/认证）；占位期为前端假数据静态标签（`RealExamPapers.vue` 内联 8 套，Variant C 形态）。
- **Prototype 决策**：按 `prototype/UI.md` 单路由 `?variant=a|b|c` 三变体（A 紧凑卡片网格 / B 列表+筛选头 / C 年份分组时间线）+ 浮动底栏切换（`PrototypeSwitcher.vue`，`import.meta.env.PROD` 隐藏，`router.replace` 保持可分享，键盘 `←/→` 循环）；throwaway 位于 `pages/student/__prototype__/RealExamPrototype.vue` + `__prototype/types.ts` + `VariantA/B/C.vue`，`__prototype` 命名即标记；独立预览路由 `/prototype/real-exam`（`requiresAuth:false`，绕过 `TrainingLayout` 与证件守卫）便于不起后端验证；**胜出 C 年份分组时间线**（按 `year desc` 分组、dot+count、虚线轴，卡片内 `levelTagType(difficulty)` + `source · question_count题 · duration_minutes分钟`），其余变体与 `PrototypeSwitcher` 归档至 throwaway branch，`main` 仅合入 C 决策。
- **练习统计（#329，已落地）**：新增 `GET /practice-mode/practice-stats?credential_id=` 聚合 `question_practice_record`，返回 `{today_count, total_count, total_days}`，均含重做；`today_count` 按 `Asia/Shanghai` 自然日 `00:00~次日00:00` 区间过滤（与 `forum_checkin` 同口径），`total_days` 按 `Asia/Shanghai` `YYYY-MM-DD` 去重（Go 侧 `t.In(loc).Format`，兼容 postgres/sqlite）；按 `current_credential_id` 分区（JOIN `question.credential_id`），独立于 `GET /practice-mode/stats`；前端 `QuestionBank` 顶部 3 宫格 + `loadCardData` 第 4 并发 + `submit`/切换后重拉。索引复用 `idx_qpr_student/created` 与 `question.credential_id`，本期无新增 migration。
- **课程热门/精品（#330，已落地）**：`course` 加 `is_hot/is_featured BOOLEAN DEFAULT FALSE` 双列及部分索引 `WHERE is_hot/ is_featured`（`000015_course_hot_featured`，允许叠加）；新增 `GET /courses?credential_id=&filter=hot|featured|all`（`all` 缺省），`GET /catalog/tree` 不改造；前端 `CourseList` 顶部 `el-tabs` 顺序 热门/精品/所有（所有最右，默认热门），热门/精品态隐藏两块 `FacetCard`、保留分页，封面角标；管理端 `CourseCatalog` 表格两列行内 `el-switch`（`PUT /admin/course/:id` 透传）+ 编辑抽屉两 `checkbox`（新建可归类）。
- **侧栏二级（#327，已落地）**：`config/navigation.ts` 由扁平改为树形（学员 4 组：学习中心/题库与考试/互动与工具/个人；管理 4 组：总览/用户与内容/教学管理/系统），一次性切换无 flag；`AppSidebar` 同上。

## 备选

- **不做独立页而用 `mode='real-exam'` 嵌入 `QuestionBank` 状态机**：拒绝，`QuestionBank.vue` 已 484 行且与 `quit/saveProgress` 耦合，嵌入会污染会话守卫与进度保存。
- **侧栏平级独立项（真题与题库练习并列）**：拒绝，真题属题库子集且侧栏已拥挤（12 项），子项语义更清晰。
- **统计复用 `GET /practice-mode/stats` 扩展**：拒绝，旧 `stats` 返回题库规模与正确率聚合，语义与练习行为计数不同，独立 `practice-stats` 更清晰。
- **单枚举 `course.badge` 或独立关联表**：拒绝，双 bool 直观、`WHERE is_hot` 查询简单且可叠加，后续加第三类 badge 再演进一步。

## 后果

- 占位期真题无 migration/API 变更（统计与热门/精品除外）；`QuestionBank` 仅新增一卡片与路由跳转；二级页复用 `CredentialStore.current.id` 过滤；后续演进再引入 `real_exam_paper` + `real_exam_paper_question` 及 `GET /real-exam/papers?credential_id` 等接口，可复用 `gradeQuestion` 判分与 `AnsweringSessionShell`。
- 练习统计新增 DTO `PracticePracticeStatsDTO` 与 handler `GetPracticeStats`，与 `stats_aggregate` 解耦；前端 `practiceModeApi.getPracticeStats()` 自动注入 `credential_id`。
- 课程 `CourseDTO`/`CourseInput`/`CourseListOptions.Filter` 扩展，`course_dto_test.go` shape-lock 已同步 `is_hot/is_featured`。
- Prototype 分支保留（`feat/ai-assistant-feature-pages` 已合并入本分支，无冲突；`__prototype` 与独立 `/prototype/real-exam` 为 throwaway，供离线验证）。
