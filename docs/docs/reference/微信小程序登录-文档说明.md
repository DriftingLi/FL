# uniapp-x 微信小程序登录 · 文档与接口说明

> 技术栈：前端 uniapp-x（.uvue）/ 后端 Go
> 用途：微信小程序一键登录完整链路参考，供前后端对齐。

## 一、整体流程

```mermaid
flowchart TD
  A[登录页 微信图标] --> B[uni.login provider:weixin]
  B --> C[前端拿到 code]
  C --> D[POST /api/auth/wx-login {code}]
  D --> E[Go 后端 jscode2session]
  E --> F{openid 是否已注册}
  F -- 老用户 --> G[签发 JWT 返回 token+user]
  F -- 新用户 --> H[自动建账户绑定 openid]
  G --> I[前端 setAuthData 跳转 choose-cert]
  H --> I
```

## 三、后端 Go（需实现）

### 核心：微信服务端登录凭证校验 code2session

- 中文文档（必读）：https://developers.weixin.qq.com/miniprogram/dev/server/API/user-login/api_code2session.html
- 英文接口参考：https://developers.weixin.qq.com/miniprogram/dev/api-backend/open-api/login/auth.code2Session.html

**请求：**
```
GET https://api.weixin.qq.com/sns/jscode2session?appid=APPID&secret=SECRET&js_code=CODE&grant_type=authorization_code
```

**响应：**
```json
{ "openid": "...", "session_key": "...", "unionid": "...", "errcode": 0, "errmsg": "ok" }
```

常见错误码：40029 invalid code、45011 频率限制。

### 接口契约（前后端约定）

- 方法/路径：`POST /api/auth/wx-login`
- 请求体：`{ "code": "前端uni.login拿到的临时凭证" }`
- 完整 URL：`http://<host>/api/auth/wx-login`（`/api` 已是后端全路径根；前端 config/env.uts 的 API_BASE_URL 自带 /api）

**后端逻辑：**
1. 用 `appid=${WECHAT_MINI_PROGRAM_APP_ID}`（GitHub Secrets `WECHAT_MINI_PROGRAM_APP_ID`，勿硬编码）+ AppSecret（微信公众平台「开发设置」取，存服务端）调 jscode2session 换 `openid`
2. 按 openid 查用户：
   - 已绑定 → 直接登录
   - 未注册 → 以 openid 为唯一键自动建账户并绑定
3. 签发 JWT，返回平铺结构：

```json
{
  "token": "jwt字符串",
  "user_id": 1,
  "username": "student",
  "name": "微信新学员",
  "role": "student",
  "avatar": "",
  "isNew": true
}
```

> 注：`isNew` 仅新用户返回 true，前端据此弹"已为您自动注册账号"；老用户可不带。

**实现落点（2026-08）**：`backend/internal/service/wechat_auth_service.go`（code2session / 查建用户 / 签发）+ `backend/internal/api/wechat_auth.go`（路由与信封）。与上文的差异：响应 data 实际为 `{ token, refresh_token, user_id, account, username, name, role, avatar, isNew }`——在契约之上补双令牌（ADR-0016）与 account 字段；自动注册 account 取 `wx_`+openid 前 12 位，昵称「微信学员」+openid 后 6 位；并发首登由 `hrwai_users.wechat_openid` 唯一索引兜底；错误码 40029/45011/40226 分别映射为凭证失效/频率限制/风险拦截文案（HTTP 400）。凭证经 `WECHAT_MINI_PROGRAM_APP_ID` / `WECHAT_MINI_PROGRAM_APP_SECRET` 环境变量配置（与网页端扫码登录的开放平台凭证 `WECHAT_OPEN_PLATFORM_*` 严格区分，两套 AppID/AppSecret 不可混用）。

## 四、小程序后台配置

- AppID：通过 GitHub Secrets `WECHAT_MINI_PROGRAM_APP_ID` 注入（`training-app/.../manifest.json` 的 `mp-weixin.appid` 在 CI 中由 `${{ secrets.WECHAT_MINI_PROGRAM_APP_ID }}` 写入，勿硬编码）
- AppSecret：微信公众平台 → 开发管理 → 开发设置（后端保管，勿下发前端）
- 服务器域名：`www.gccsmile.com:51820` 加入「开发设置 → 服务器域名 → request 合法域名」
- 开发期：微信开发者工具可勾「不校验合法域名」
