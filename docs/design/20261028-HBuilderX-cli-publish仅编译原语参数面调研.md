## 2. 官方是否明写「不带 `--upload` 即仅编译」

**明写。**同页「使用示例」第一条的官方注释原文：`# 仅编译uni-app项目到微信小程序`，对应命令行 `cli publish --platform mp-weixin --project 项目名称`。

配套语义：`--upload`「只有值为 true 时生效」（即默认不上传）、`--appid` 条件必填。同一措辞在 **[发行 - WEB](https://hx.dcloud.net.cn/cli/publish-h5)** 也出现（`# 仅编译uni-app项目到H5，不上传uniCloud前端网页托管`）⇒「publish = 编译 + 可选上传，不传即只编译」是该文档系列的通用口径、非 mp-weixin 孤例。**官方明写，无歧义。**

## 3. 开发者工具：publish 是否要求/拉起，及「仅编译不启动」原语逐条有无
