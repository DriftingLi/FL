## 决议（2026-11-12 讨论收口）

- **Q1 数据在库**：用户在 Web 真题页 `https://training.gdyidao.cn/training/real-exam` 亲见卷列表 ⇒ 采纳**纯移动端接入**，不动后端、不写库；本机无库可连此事不再阻塞。
- **Q2 形态**：**真题卷列表页**（复用后端套卷模型）。练习页内「真题」筛选入口**不做**——与 `ADR-0022` 全池隔离冲突。
- **Q3 8 个源文件**：仓内与本机皆无 ⇒ 补数据不可执行（ADR-0022 的补卷路径实际失效）。**用户裁定：不立票、也不进验收**，只要真题练习功能可用。
- **Q4 新页落点**：`pages/practice/real-exam-papers.uvue`（入口在 practice 四宫格；纳入 PRACTICE_PAGES 多得一道「不得直接 `uni.request`」护栏）。
- **Q5 整卷考试**：首期**含**，走 `mock-exam?paper=<id>` 对齐 Web（`frontend/src/pages/student/MockExam.vue:104-120` 有 paper 即进页即开考），给 `useMockExamSession.applyOptions` 加 paper 分支。
- **Q6 呈现**：逐项对齐 Web；页头文案用**「历年真题」**（与入口格一致，Web 的「真题练习」是 Web 措辞）；首期**不显示练习进度数字**。
