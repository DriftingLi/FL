# #1965 管理端 `@media` 逐条判定

> 2026-10-26。依据 **ADR-0084**（管理端只保桌面）：管理端 ≤768 的 `@media` 只允许「防溢出 / 换行」类兜底；"移动端观感微调"（字号、间距、内边距）不再保留。
> 全站 26 条 `@media` / 21 个文件，逐条判定如下。**外壳 2 条**与**非管理端**（学员 / 讲师 / 查看器 / 共享组件）不在 ADR-0084 射程，只登记不判。

## 本轮改动

**删除 3 条纯观感微调**（只影响 ≤480 的字号/标签宽，删除后桌面零变化）：

- `admin/Dashboard.vue` 的 `@media (max-width: 480px)`（`.stat-value` / `.stat-label` 字号）
- `admin/Statistics.vue` 的 `@media (max-width: 480px)`（同上）
- `admin/ContentGenerate.vue` 的 `@media (max-width: 480px)`（表单标签宽 `70px !important` + 字号）

## 沉淀的规则

写入 `docs/agents/ui-conventions.md`：**管理端 ≤768 的 `@media` 只允许「防溢出 / 换行」类兜底**；字号、间距、内边距这类观感微调不再新增（ADR-0084），新增即违规。

## 验证

删除三处后，三张受影响页面（`/admin/dashboard`、`/admin/statistics`、`/admin/content-generate`）在 375 / 768 下**页面级横向溢出 0 例**（CDP 复测，见 #1965 评论）。
