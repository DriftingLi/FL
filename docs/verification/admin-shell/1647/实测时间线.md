夹具：`manage.localhost:5199`（本机 dev server = 真实前端代码）+ 真实登录表单 + 真实守卫；
只替身 `/api/**`，且**只让能力集端点落后于导航一拍**（延迟 800ms 返回 20 个能力）。
账号能力集：`admin.access` 等 20 个键（超级管理员形态）。

## 改前（`9e1702db`）

```
+  939ms POST /api/auth/admin-login → 200 (role=admin)
+  952ms GET  /api/auth/me → 200 (role=admin)
+  953ms GET  /api/admin/me/capabilities → 延迟 800ms 后返回 20 个能力
+ 1370ms 能力集未到达时 → /login（守卫已在判，只是还没判完）
+ 1754ms GET  /api/admin/me/capabilities ← 200 (20 caps)
+ 3385ms 能力集到达 2.4s 后 → /admin/no-access ｜ h1=「当前账号还没有管理权限」｜ 侧栏项=20 ｜ 固定签=「仪表盘」
```

截图：`改前-全权限管理员落无权限页.png` —— 侧栏 20 项、固定签「仪表盘」，内容区却是无权限页；
能力集到达后侧栏恢复，但**没有任何东西把内容区导航回去**（等 2.4s 仍在原页）。

## 另外两条路径（同夹具，改后）

| 场景 | 首次落点 | 动作 | 结果 |
| --- | --- | --- | --- |
| 能力集端点 500 | `/admin/no-access`，h1=「管理权限加载失败」（截图 `能力集装载失败-加载失败页与重试.png`） | 点「重试」（服务恢复） | `+2.5s GET capabilities → 200 (2 caps)` → `/admin/dashboard`，h1=「欢迎回来，admin1！」 |
