# #1832：删掉没人用的 pdfjs-dist（原议题是「4 → 6 升级」）

## 结论

`pdfjs-dist` 是**没有任何 import 方的存量依赖** —— 本仓的 PDF 预览一直是 `<iframe>` + 浏览器**原生阅读器**，
不是 pdfjs。所以这票的正确收口不是在 4 与 6 之间选一个，而是**删掉**：改版本号改不动任何行为，只会把
一个不参与构建的包继续留在 lockfile 里。

判据：`grep -r pdfjs` 在 4→6 之前只剩三处 —— `package.json` 的声明、`vite.config.ts` 的一条
`manualChunks` 规则（`if (id.includes('/pdfjs-dist/')) return 'pdfjs'`，从未命中过，因为没人 import）、
以及 dependabot 的 ignore。产物里从来没有 `pdfjs` chunk。

## 证据 1：删掉后构建产物逐字节相同

同一台机器、同一条 `npm run build`：

| | 文件数 | 总字节 | 预压 |
| --- | --- | --- | --- |
| 删前 | 1378（含 .gz） | 59,739,593 | 176 文件 27213 KB → 6270 KB |
| 删后 | 1378 | 59,739,593 | 176 文件 27213 KB → 6270 KB |

`dist` 全量 SHA-256 对比：**1378 个文件，0 处差异**（比对脚本口径见下）。也就是说这个依赖对产物
的贡献是 0 字节 —— 它连 tree-shaking 都没参与，因为它从未进入 import 图。

## 证据 2：真实浏览器里 PDF 预览仍然好使（两个消费面）

脚手架（一次性，验证后已删）：vite dev 起真实组件 —— 简历预览 `OnlineResumePdf`（`fetch` → `blob` →
`<iframe>`）与课件预览 `DocumentViewer`（`HEAD` 探活 → `<iframe>`），只 stub 令牌、把「PDF 端点」指向
仓库里真实存在的 **3 页** 报告（`backend/storage/reports/evaluation_report_1_20260629160728.pdf`，77,673 字节，
`%PDF-1.4`）。浏览器：本机 Edge headless new，puppeteer-core 驱动，视口 1280×2400。

| 用例 | 期望 | 实测 |
| --- | --- | --- |
| A 简历预览（正常） | 出现 iframe，src 是 blob，内容是那份 PDF | iframe 1232×420，src `blob:…`；blob 77,673 字节、`%PDF-1.4`、**/Type /Page = 3**；原生阅读器页数显示 **1 / 3** |
| B 简历预览（HTTP 500） | 错误态 + 重试，不白屏 | 无 iframe，文案 `简历加载失败` + `重试` 按钮 |
| C 课件预览（正常） | 出现 iframe，src 指向文件 | iframe 1232×559，src `/report.pdf`，工具栏显示文件名 |
| D 课件预览（HTTP 500） | 空态替代 iframe | 无 iframe，文案 `missing.pdf … 下载文档 / 在新窗口打开` |

DOM 层读数：页面 iframe 总数 **2**（A、C 各一），B/D 均未产生 iframe；整页与四个用例的截图见同目录 png。
`report.json` 是机器读数原文。

> 截图里出现的「和润天下人工智能科技」是**历史报告文件的内容**（数据库里存着的 2026-06 生成的 PDF），
> 与本次改动无关。

## 复现

```powershell
# 1) 产物同一性（任一版本各跑一次）
npm run build
Get-ChildItem dist -Recurse -File | Sort-Object FullName |
  ForEach-Object { "$($_.FullName) $((Get-FileHash $_.FullName -Algorithm SHA256).Hash)" } |
  Set-Content dist-hashes.txt

# 2) 浏览器四例：起脚手架（见本目录里删掉的 harness-1832/ 结构）+ puppeteer-core 驱动本机 Edge
```

## 改动面

- `frontend/package.json`：删 `pdfjs-dist`（`npm install` → lockfile 少 3 个包）
- `frontend/vite.config.ts`：删那条从未命中的 `manualChunks` 规则
- `.github/dependabot.yml`：删 pdfjs-dist 的 major ignore（包没了，这条 ignore 也就没有对象）
- `README.md` / `docs/reference/CODE_WIKI.md`：依赖清单去掉 pdfjs-dist

本地三件套：`npm run type-check` 0 错、`npx vitest run` 149 文件 / 1357 用例全过、`npm run build` 176 文件。
