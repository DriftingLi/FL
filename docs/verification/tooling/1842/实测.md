## 判据二：A/B 像素比对（这是「人工验」的机器版）

同一份组件代码、同一台机器、同视口（1440×1100），只切 `vditor` 版本：

| 主题 | 差异像素 | 最大通道差 | bbox |
| --- | --- | --- | --- |
| 浅色 | **0 / 1,584,000** | 0 | None |
| 深色 | **0 / 1,584,000** | 0 | None |

深色下实测取色也逐项相同（`body color rgb(241,245,249)` / 代码块底 `rgb(15,23,42)` / 工具栏图标
`rgb(148,163,184)` / 表格单元格 `transparent`）—— 见 `colors-v3.json` 与 `colors-v4.json`。

> 截图里的表格单元格发白、代码块发白**不是** v4 引入的：脚本是直接改 `data-theme` 属性、没走主题 store，
> 所以 `isDark` 仍是 false、代码块用 light 的 `github` 配色。v3 与 v4 在这点上**逐像素一致**。

## 已知毛刺（与 3.x 同款，本次不动）

IR 模式会请求 `/vditor/dist/css/content-theme/light.css`，而白名单**故意不复制** `content-theme`（插件注释里
写了「未启用则不复制：emoji、content-theme…」）—— 该 URL 实际返回的是 SPA 兜底的 HTML（`Content-Type: text/html`），
不是样式表。两个版本行为完全一样，属存量；真要修就往白名单加 `css/content-theme` 一行，但那份样式会叠加到
正文上，可能改观感，故本票不夹带。
