# 技能供给与管线归属（仅移动端线）

**适用面**：本文件服务**移动端（uni-app-x 学员端）那条线**。下面四条约定是**这条线的工作方式**，**不是全仓约定** —— 故它随移动端 `AGENTS.md` 导航；**前后端会话不读它、也不受它约束**（照 `docs/agents/issue-dispatch.md` 的先例）。

**决策与实测出处**：`docs/adr/0024-技能供给与管线归属.md`（含扫描根 rank 表、100 + 3 个死副本文件、12 个独有技能等逐项实测）。来源票：#1230；落地：PR #1231 / #1236。

## 生效面：技能从哪里被加载（判据，每次现测）

harness 的技能扫描根由 `dsh-skill-filesystem` 决定，**`findProjectRoot` 从 cwd 向上找到最近的 `.git` 为止**，扫描根依次为：

| rank | 路径 | 本仓实测 |
| --- | --- | --- |
| 100 | `projectRoot/.dsh/skills` | **不存在**（且**裁定不放**：rank 100 会改变所有会话的生效版本，见「不做」） |
| 200 | `projectRoot/.agents/skills` | **不存在** |
| 300 | 自定义根 | 未配置 |
| 400 | `~/.dsh/skills` | 用户级 |
| 500 | `~/.agents/skills` | 用户级 |
| 600 | bundled（插件自带） | **实际生效的就是这一层** |

⇒ 直接推论，也是本文件存在的理由：**在移动端子树里放技能副本（`training-app/…/.agents/skills`、`.opencode/skills`）不会生效** —— 它们不在任何扫描根下。rank 小的优先，所以「往仓里放一份」不但无效，还会在将来某次路径调整后**静默改变所有会话的技能版本**。

## 四条约定

### 1. 生成物不入库

harness 注入的技能目录 / 上下文块（例如一段 `<available_skills>` XML）**一律不进版本库**：它是**必然过期**的产物，没人维护它，且会把当时机器的死路径固化进文档（先例：移动端 `AGENTS.md` 里 65 行机器生成块，内含 3 条 `E:\FL` 死路径；由 PR #1231 清退）。

判据：一段内容**是否由工具生成、且会随环境变化** —— 是，就写指针（指向真源），不写内容。

### 2. 第三方技能内容不入库

技能内容由 **plugin / 包管理器**分发；仓库只记录**来源与版本**。

- 现成的来源记录：移动端 `skills-lock.json`（37 个键，每条 `source` / `sourceType` / `skillPath` / `computedHash`）。它记的是**上游路径**，**不指本仓路径** —— 这是它的正确形态，不要为了「看起来完整」改成指向仓内副本。
- 仓内副本若已存在（如 `.agents/skills/**`、`.opencode/skills/**`），按对应票清退：它们是**惰性**的（全仓 `git grep` 命中 0），但会制造「改错了那一份」的误操作面。
- 上游许可是 MIT（© 2026 Matt Pocock，插件侧 `VERSION` = v1.2.3）；**随仓分发内容副本而不带 LICENSE 是合规缺口** —— 第 2 条同时是对该缺口的处置（不进库即无分发）。

### 3. 技能改动独立成 PR

入库的技能文件里可能带 `.yaml` / `.sh` / `.cjs`（先例：`.agents/skills/**` 含 37 × `agents/openai.yaml` + 3 × `.sh` + 1 × `.cjs`），**这些扩展名不在 `pr-evidence` 的低风险白名单**（白名单 = `*.uts` / `*test.js` / `*.md` / `jest.config*.js`，判据源 `.github/workflows/pr-evidence.yml` 的 `LOW_RISK_NON_RUNTIME`）。

⇒ 把技能文件改动**混进任何带 `.uvue` / `.uts` 的 PR**，会把整单降级为**常规运行时面**：① 真机与 ② 微信开发者工具**双双变必过**。

**做法**：技能文件（及其忽略规则）单独一票、单独 PR、单独 revert。反过来，如果改动集只有 `.md` 这类文件，按移动端 `docs/adr/0008` 属**非运行时面**，PR 正文写「免（未命中运行时面）」（先例 #908）。

### 4. 引用技能文档引小节名，不引行号

技能来源有多份快照时行号**必然不同**（实测同一份 `grilling`：A 版 29 行 / B 版 23 行）。引用时写**小节名**（如「§0 形态判定」「文末判据」），不写 `:123`。

行号只在报告**当次实测**时使用，并同时给出基准（commit 或日期）。

## 本仓不做的两件事（2026-09-21 裁定）

- **不在根 `D:\FL\.dsh\skills\` 落技能**：那是 rank 100 的扫描根，**压过用户级(500)与插件(600)** ⇒ 一旦放入就改变**所有会话**（含前后端）的生效版本。
- **不新建根 `docs/agents/skills.md`、也不在根 `AGENTS.md` 加指针**：会让这四条进入所有会话的常驻上下文，收益未证明。

判据（每次现测，不按记忆走）：

```powershell
Test-Path D:\FL\.dsh            # 期望 False（放了东西就是踩了第一条）
Test-Path D:\FL\.agents         # 期望 False
git ls-files "training-app/叉车维修培训学员端跨端应用/.agents/skills"   # 期望 0 行
git ls-files "training-app/叉车维修培训学员端跨端应用/.opencode/skills" # 期望 0 行
```
