## 2. 替换集合（恰好 10 张）

`static/tabbar/{home,course,ai,forum,profile}[-active].png` —— 对应 `pages.json:493-523` 的 5 组 `iconPath` / `selectedIconPath`。**其余 108 张 `static/icons/*` 一张不动**（C2 台账 §1/§4 给出「为什么不换」的逐张依据）。

## 3. 出图步骤（10 张，逐张执行）

1. 源：`切图-svg11.23/切图-svg11.23/底部导航栏/<中文名>.svg`（10 个：首页/课程/AI学/交流/我的 × 默认/选中）。
2. 抽 `<image>` 内嵌 base64 → 位图：常规 **200×200 RGBA**、AI学 **360×307**、交流选中 **200×168**（`<path>` 数 = 0，是位图壳）。
3. **Lanczos 降采样**：保持宽高比缩到边长 ≤81（禁止放大）；在 **81×81 透明画布居中**归一，得到目标位图。
4. **调色板取优**：逐张 `min(RGBA, 256色)`，≤256 色量化反涨的张保留 RGBA（image-assets.md「出图口径」）。
5. 覆盖同名 `static/tabbar/*.png`；**文件名与 `pages.json:496-521` 的引用保持不变**（见 §1 裁定 2）。

## 4. 验收

- **截图对照**：原型整屏底栏裁图（C1 #2850 证据在 `C:\Users\ZHENG\AppData\Local\Temp\proto-tabbar\crops\`，9 屏）+ tabbar 5 组两态目视一致；结构+视觉一致即可，不做像素级硬门（image-assets.md 资产验收口径）。
- **主包读数**：替换前后各跑一次 `npm run build:mp-weixin-buildonly`，打 `mainBytes=`；ADR-0071 建议线 1.5 MiB，破线静默（G7a 只打不判红）；本批只换 10 张（#2508 曾记 81×81 重出 17,801 B vs 现网 8,962 B，净 +8,839 B 量级）。
- **边界副本眼验**：出图后按 §1 裁定 6 眼验 8 个 `chevron` 副本，结论回填 C2 台账明细。
- **证据形态**：替换 PR 命中运行时面（`.png` 在 `static/` 下，非 `*.uvue`/`*.uts`/三份 json ⇒ 早退放行「免（未命中运行时面）」）时按 A1 写正文一行 `跑于 <sha7>` + 门读数行；截图对照**仍要做**（不计入 A1 证据）。
