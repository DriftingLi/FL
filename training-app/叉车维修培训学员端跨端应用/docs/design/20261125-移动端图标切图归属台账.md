## 2. 复算方法（可重跑，别凭记忆引用数字）

**像素链**：`RGBA → 合成白底(255,255,255,255) → L 灰度 → resize 24×24 (BICUBIC) → 展平去均值 → L2 归一化 → 余弦相似度`。188×118 全矩阵取每张切片的最佳匹配。

**两条判定线**：

| 线 | 取值 | 含义 |
| --- | --- | --- |
| 同一张（高置信） | sim ≥ 0.97 | 像素级同图，允许输出压缩差 |
| 有对应件（判定线） | sim ≥ 0.955 | 同图或仅 alpha 边缘/轻微改色；**0.955 是复现票内 93/77 的唯一取值** |

**哨兵自检（本方法与票内计数逐项一致）**：

| 读数 | 本台账复算 | 票内 | 结论 |
| --- | --- | --- | --- |
| sim ≥ 0.97 的对数 | 101 | 101 | 一致 |
| 其中尺寸一致 | 82 | 82 | 一致 |
| 现网 118 张被覆盖 | 93 | 93 | 一致 |
| 切片无对应件 | 77 | 77 | 一致 |

复核脚本可重写：读两个目录 → 上式 → 阈值计数（脚本不必入仓，方法即本节四行）。

## 3. 五档判据（机械规则，按序判定，先中先出）

- **R1** 目录 = `底部导航栏` ⇒ `UI_ASSET`，动作 **换（tabbar 替换批 C1）**。槽位与文件名不变，只换像素内容。
- **R2** sim ≥ 0.955 ⇒ `UI_ASSET`，动作 **不换**（已随包；尺寸不同只在台账记录）。含内容型的同图，例如 `mascot_robot_full.png` ↔ `icons/help-center/mascot.png` = 0.9998。
- **R3** 文件名命中内容型前缀（`logo` / `mascot` / `illustration` / `avatar`）⇒ `CONTENT_STATIC`，动作 **随设计稿改版**（不按图标对齐，不排进图标批）。

## 8. 方法敏感性：票内数字的来路（重要，别混用）

票内同一段里引用了**两次不同实现**的读数，本台账按第 2 节口径统一：

- 四个计数（101 / 82 / 93 / 77）与 77 张目录分布 ⇒ 只有 **24×24 BICUBIC + 白底** 能逐项复现。
- 票内 8 组反例的三个值（`0.603` / `0.868` / `0.553`）与「10 张 tabBar 全部 <0.92」⇒ 属 **24×24 LANCZOS** 实现（本台账实测 0.6029 / 0.8678 / 0.5525、tabBar 最高 0.9176，逐值对上）。
- 换滤波器的影响面很小、但确实存在：**1 个资产**（`icons/ai-chat/chevron-model.png` ↔ 33×33 `icon_chevron_left_black.png`）的 8 个副本在 0.955 两侧翻转（0.9584 ↔ 0.9548），现网覆盖面 93 ↔ 92。

**裁定**：台账统一用 BICUBIC 口径（它撑住 77 张的分配）；tabBar 的口径改写为「10 张全部 <0.93（BICUBIC 最高 `ai.png` 0.9226）」，票内「<0.92」作历史读数保留；8 个边界副本在明细里标「边界对」，**换不换等出图后一并人眼确认**。
