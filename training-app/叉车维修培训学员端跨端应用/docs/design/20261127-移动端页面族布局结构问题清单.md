# 移动端页面族布局结构问题清单（2026-11-27 实测）

> **只报告、不建机检、不进门。** 本文件是票 #2911（父规格 #2897）的判断面取证：逐族记录**页头行为 / 层级 / 间距 / 触摸目标 / 箭头方向 / 骨架**七类结构问题，每条带页面与源码位置，按「严重度 × 影响页数」排序，作为后续 P3 结构改造票**切分依据**。
> 不含主观审美评分；圆角与字号不在本票范围（归 #2910）。**本文件不提出任何新判据**，落地口径见文末「不进门」段。

## 0. 结论摘要

- **页头面**：61 页里 **55 页**用 `components/app-nav-bar`（唯一页头件）、1 页用它的薄包装 `components/ai-chat/ai-chat-nav`、5 页无页头件。透明页头 7 页里有 **4 种参数组合**（H5）。骨架（status-bar 占位）有 **3 套写法**：手写 `status-bar`（3 页）、组件自测（55 页）、以及**没有任何占位**（register/forgot-password 2 页，且这两页还是全仓唯一未设 `navigationStyle: custom` 的页）。
- **层级面**：`z-index` 共 **17 处声明、10 个不同取值**（10/90/91/100/101/200/201/300/301/999）散在 **12 个文件**，**没有刻度表**，且**页头自身没有 `z-index`**；11 处 `position: fixed` 浮层分布在 9 个文件，与页头/滚动容器无共同约定。
- **间距面**：页面级水平内距有 **4 个族间档位**，且 **9 个页面内部自己就有 2–5 档**（同一页 32/28/24/20/16 混用）；卡内距与页面内距常常同值。**注意**：这一项与机检不矛盾——`npm run audit:spacing -- --all` 读数是 **WARN 0 / INFO 0 / SKIP 203**（现有判据全在「卡内距 = 页面边距」这类可判的规则上，本清单元件是「同一页内多档」这类判断类，见 §4 与条目详述 S1）。
- **触摸目标面**：`-hit` 命中层（116 处 / 41 文件，含类定义与模板引用）、`padding` 撑开、共享件 `app-icon-button`（7 处 / 6 文件）三套实现并存；大量 `<88rpx` 的定高声明靠父级或覆盖层补足，**最终命中区静态无法复算**（T3）。
- **箭头/图标面**：左向箭头无专属资源，**4 处借用 AI 模型选择器的 `chevron-model.png`**；右向箭头 2 套资源；展开态 3 套表达；图标载体 3 套（位图 PNG / emoji / 字形）。emoji 与字形随系统字体渲染，**尺寸与颜色不受控**。
- **骨架面**：`<scroll-view>` 全项目 128 处 / 84 文件，是主流滚动模型；**53 个页面**根容器写 `height: windowHeight + 'px'`、8 页不写；页内二级 tab 有 4 套自绘 + 1 套共享件。

## 1. 口径

- **扫描面**：`training-app/叉车维修培训学员端跨端应用/pages/**` 下 61 条路由（`pages.json` 含 `subPackages`），加 `components/**` 的共享件。
- **取证方式**：源码静态读（结构、类名、样式声明、组件传参）+ 对照 `docs/design/20261125-移动端61页N×G归属台账.md`（**仓库根**，不在移动端 docs 下）的 N/G 归属。**未做真机逐页复核**，涉及「看起来如何」的条目已在正文标注；本票不做截图取证（#2320 起日常不产截图）。
- **页数口径**：`N` = 受影响**页面**数；共享件按引用页数计；组件内部问题按该件覆盖的页数计。
- **已知未合并工作**：`D:/FL/wt-mobile-arrow-touch-targets`（分支 `fix/mobile-arrow-touch-targets`，提交 1e267270「Improve mobile arrow touch targets」）改了 `app-nav-bar.uvue` 返回键、`composables/useTouchPress.uts`、`check-in.uvue`，**未合入 master**。本文件凡涉返回键 / 箭头尺寸的条目，均以 master 现状为基线并注明该分支，避免后续票重复立项。
- **不重测面**：图片比例已在 [图片尺寸与容器比对照表](20261127-图片尺寸与容器比对照表.md) 一次性现测，本文件只引用其结论（F1），不重复测量。

## 2. 优先级规则

> **优先级 = 先严重度、后影响页数**（即「严重度 × 影响面」的主序展开）。

| 严重度 | 判据（判断类，本文件自定，不进门） | 落位 |
| --- | --- | --- |
| **高** | ① 同一语义在全站有 ≥2 种实现且**无法从单一文件读出真值**；② 会造成**可见的重复/错位**（双标题、层级叠加）；③ **同一页内**自相矛盾 | P1 |
| **中** | 同族或跨族**可见不一致**（内距/尺寸/资源成对出现但不同值），有单一真源可收 | P2 |
| **低** | 单点观感、边界值、或只是「口径不可机检」的说明 | P3 |
