## ①a 抓到一个真 bug（并已修）

首版把浮层面板也做成 `position: fixed` 塞进 fixed 遮罩里 → 面板被遮罩在 z 序上盖住，**点输入框先命中遮罩 ⇒ 面板一点即收起**（用户实测症状 (b)）。
修复：面板改回 practice-do `.answer-card-sheet` 的可用形态 —— 面板作遮罩的**普通 flex 子**（不做 fixed）、遮罩 `justify-content: flex-end` 落底、`margin-bottom` 抬到键盘上沿；textarea/input 去掉 `:fixed`。重推真机后复验：键盘正常弹起、面板贴键盘上沿、标题栏未被顶走（即上表证据）。
