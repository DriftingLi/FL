- 对照本工作树 9/17 的**本地编译产物** `unpackage/cache/.app-android/src/pages/profile/components/wrong-question-card.kt`
  （30598 B / 2026-09-17 15:30:02）：「我上次选的答案」「暂无解析」「record-question-img」「最近」**都在**里

**为什么没把新包推上去（阻塞，附原始报错）**：本会话的 HBuilderX CLI 通道不可用，
`cli.exe` 每次调用都返回


并且 `cli open` 本身报 `启动超时`（HBuilderX CLI 失败时退出码恒为 0，故只能读文本）。已排除的几项：

- 不是主程序没起：`Get-Process HBuilderX` = pid 22100 存活（本会话全程未触碰、未 kill）；
- 不是版本错配：主程序与 `cli.exe` 同属 `D:\软件\HBuilderX.5.23.2026080626\HBuilderX\`；
- **是命名管道被拒**：`cli.exe` 走 `QLocalSocket`（其导入表里就是 `RPC::LocalSocketClient` + `QLocalSocket`），
  而本会话直接连主程序的命名管道 `\\.\pipe\hbuilderx_1789695022251_pipe` / `…0223065_pipe`

### 「题干图片」——仍未主张，且本轮**查明了它为什么无法从客户端行使**

不是没试。事实链（都可复现）：

1. **全 App 只有一处渲染题目配图**：`pages/profile/wrong-questions.uvue:49` 把 `item.image_url` 交给错题卡片
   （`record-question-img`）；`api/wrongQuestion.uts` 是唯一取数面（全仓 `grep image_url` 只命中
   `api/wrongQuestion.uts` 与 `api/resume.uts`）。
2. **练习页根本不渲染题目配图**：`pages/practice/practice-do.uvue` 里的 `<image>` 只用于底栏图标
   （答题卡 / 收藏），题干与选项都是纯文本 ⇒ 在练习流程里**看不出**哪道题带图，也就**无法挑选**一道带图题去答错。

   190–200 色区间。**这个扫描说明的是「练习页没有配图位」，不是「题库里没有带图题」** —— 两者别混。）
3. 本账号（叉车司机N1证）现 9 道错题里没有带图题：错题本卡片列表按像素扫不到高度 ≈493px（320rpx）的图块。
