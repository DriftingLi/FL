## 1. 设计稿界面概述

设计稿包含两个移动端页面：

### 页面 A：设置（Settings）
- 顶部：返回箭头 < + 标题「设置」
- 列表项（cell 样式，右侧带 > 箭头）：
  - 账号与安全
  - 收货地址
  - 关怀模式（显示状态：未开启）
  - 通知设置
  - 清理缓存（显示数值：11.9 MB）
  - 通用
  - 登录设备管理
- 分组分隔线
- 隐私分组：
  - 隐私
  - 个人信息收集清单
  - 第三方收集清单
- 分组分隔线
  - 关于我们
- 底部：「退出登录」按钮（全宽，居中文字）

### 页面 B：个人信息（Personal Info）
- 顶部：返回箭头 < + 标题「个人信息」
- 列表项（cell 样式，右侧带 > 箭头）：
  - 修改头像（右侧显示头像缩略图）
  - 修改昵称（右侧显示当前值：学员07dslj）
  - 修改密码
  - 更换手机号（右侧显示脱敏手机号：137******12）
  - 注销账号
  - 我的账号
- 底部：「退出当前账号」按钮（红色文字，居中）

## 6. 信息架构差异

### 设计稿的信息层级

```
设置（Settings）
├── 账号与安全 ──→ 个人信息（子页面）
│   ├── 修改头像
│   ├── 修改昵称
│   ├── 修改密码
│   ├── 更换手机号
│   ├── 注销账号
│   └── 我的账号
├── 收货地址
├── 关怀模式
├── 通知设置
├── 清理缓存
├── 通用
├── 登录设备管理
├── ── 分隔 ──
├── 隐私
├── 个人信息收集清单
├── 第三方收集清单
├── ── 分隔 ──
├── 关于我们
└── 退出登录
```

### 当前代码的信息层级

```
设置（settings.uvue）
├── 账号
│   ├── 头像
│   ├── 昵称
│   ├── 手机号
│   └── 角色
├── 关于
│   ├── 关于我们
│   └── 当前版本
└── 退出登录
```

**关键差异**：
1. 设计稿采用设置到个人信息两级导航，当前代码将所有信息平铺在单一页面
2. 设计稿的「账号与安全」作为入口指向子页面，当前代码直接展示头像/昵称等字段
3. 设计稿有独立的「个人信息」页面，当前代码没有

## 8. 组件设计草案

### SettingsCell 组件（可复用）

```vue
<template>
  <view class="cell" @click="$emit('click')">
    <text class="cell-label">{{ label }}</text>
    <text v-if="value" class="cell-value">{{ value }}</text>
    <image v-if="avatar" class="cell-avatar" :src="avatar" mode="aspectFill" />
    <text v-if="arrow" class="cell-arrow">›</text>
  </view>
</template>

<script setup lang="uts">
defineProps<{
  label: string
  value?: string
  avatar?: string
  arrow?: boolean
}>()
defineEmits(['click'])
</script>
```

## 9. 与现有系统的兼容性考虑

1. **现有代码复用**：settings.uvue 中的头像/昵称修改逻辑可直接迁移到 personal-info.uvue
2. **API 兼容**：新页面复用现有 authApi（updateProfileApi、uploadAvatarApi），无需后端改动
3. **渐进式重构**：可先新增 personal-info.uvue，设置页保留原有功能并添加跳转入口
4. **TabBar 兼容**：「我的」TabBar 页面保持不变，设置入口从 profile 页跳转
