# 页头右槽右入口不可见：`rightIcon` 死分支回归（#2412）

- 复核点：2026-11-10，`origin/master 929450b2`（本票 #2412）
- 结论：`components/app-nav-bar/app-nav-bar.uvue` 模板只有 `v-if="rightIcons.length > 0"` 与 `v-else`（`#right` 插槽）两段；`rightIcon ?: string`（:38）与默认值 `''`（:72）仍声明但**从不渲染** ⇒ 死 prop。

## 回归怎么发生的

`8a95e05b`（#1649，2026-10-11）的第二个提交「修复融合冲突遗留的右槽 v-else-if 悬空」。原三段链是
`v-if(rightIcon)` → `v-else-if(rightIcons.length > 0)` → `v-else`（slot）；融合时 WIP 侧已改用 rightIcons，
修复者把链收成 `v-if(rightIcons)` / `v-else` slot —— **单图标分支被整条删掉，prop 与默认值留下**。
`git show 8a95e05b -- …/app-nav-bar.uvue` 可看到被删的 `v-if="rightIcon.length > 0"` 与 `<text>{{ rightIcon }}</text>`。

## 影响面

- 唯一调用方 `components/ai-chat/ai-chat-nav.uvue:10`（该件 `rightIcon` 默认 `'⋯'`，:43）；`pages/ai-assistant/ai-assistant.uvue:4` 的 `@menu-click="toggleSidebarRight"` 因此没有可见入口。
- **MP-WEIXIN**：`useSafeArea().rightSlotWidth = 750 − capsuleLeft > 0` ⇒ 空 `v-else` 槽带宽度并挂着 `@click="onRightClick"`：看不见但点得动。
- **App / H5**：`capsuleLeft = 0`、`rightSlotWidth = 0`（`utils/system.uts` 只在 `#ifdef MP-WEIXIN` 赋值）⇒ `rightSlotStyle` 返回 `''`，空槽零宽 ⇒ 入口连命中区都没有。
- 其它调用方走 `rightIcons`（`pages/dashboard/dashboard.uvue:7`、`pages/resume/resume.uvue:4`），不受影响。

## 为什么 ③ 没拦住

`utils/aiChatDrawerContract.test.js` 的 ④ 只钉插槽分支：`class="nav-bar-side nav-bar-right"` + `@click="onRightClick"` + `rightSlotWidth`。
左槽有 `leftEntryVisible()` helper + 三条注入违规样本（2026-10-27 为 #1677 补），右槽没有对称件 ——
缺陷类是「prop 有声明、模板无引用」，而现有断言只看命中区形状、不看字形。

## 两条修法（第一性判据）

页头右槽只应有**两条**渲染路径：组件画字形（`rightIcons`，n ≥ 1 已覆盖 n = 1）或页面注入 `#right`。
`rightIcon` 是第三条、且是唯一没实现的；**恢复它 = 让「右侧字形」有两个同义 prop**，正是本次漂移的成因。

- **收编（推荐）**：`ai-chat-nav` 改传 `:right-icons="[rightIcon]"`，删 `app-nav-bar` 与 `ai-chat-nav` 的 `rightIcon` prop。代价：`ai-chat-nav` 的 prop 名变了（唯一调用方 ai-assistant 并未传该 prop）。ADR-0035 决策 17「差异用 prop 表达、fork 即违规」不反对 —— 只保留一个 prop 更贴它。
- **恢复**：三段链 `v-if(rightIcon)` → `v-else-if(rightIcons.length > 0)` → `v-else`，两套同义 prop 长期并存。

`929450b2`（#2413）已给 `.nav-bar-right` 补 `flex-direction: row`，且注释写明「单图标形态的水平位移是预期几何（字形右缘 = 胶囊左边线 − 36rpx）」⇒ 收编路线在几何上已无欠账。

## 断言落点

补 `rightEntryVisible(nav, page)`，与 `leftEntryVisible` 对称：字形（`rightIcons` 非空）、`@right-click` 接到 `toggleSidebarRight`、`<AiChatDrawerRight>` 渲染；再注入三条违规样本自证必红（去掉字形 / 拆接线 / 不渲染抽屉）。
