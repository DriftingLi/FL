# 选择学习阶段页面 — 原型图 vs 当前代码差异分析

> 分析时间：2025-08-23
> 当前代码：`pages/guide/choose-cert.uvue`

---

## 1. 总体结论

| 维度 | 差异数 | 严重程度 |
|------|--------|----------|
| 结构缺失 | 2 处 | 🔴 功能级 |
| 布局差异 | 3 处 | 🟡 视觉级 |
| 样式偏差 | 4 处 | 🟢 微调级 |

**核心问题**：当前代码缺少「热门考证详情说明」区域和底部「完成」按钮；技能等级证标签的双行展示未实现；热门考证卡片布局方向不一致。

## 2. 逐项差异对比

### 2.1 顶部导航栏

| 元素 | 原型图 | 当前代码 | 差异等级 |
|------|--------|----------|----------|
| 返回按钮 | < 箭头 | < 箭头 | ✅ 一致 |
| 标题 | "选择学习阶段" 居中 | "选择学习阶段" 居中 | ✅ 一致 |

**调整方案**：
- 删除右侧搜索按钮（`nav-search` 整个 view），原型中没有此元素。
- 微信小程序胶囊按钮由平台自动渲染，无需代码实现。

### 2.4 分组二：工程机械维修工（叉车维修方向技能等级证）

| 元素 | 原型图 | 当前代码 | 差异等级 |
|------|--------|----------|----------|
| 分组图标 | 🚜 拖拉机 emoji，绿色底色 | ⚙️ 齿轮 emoji，绿色底色 | 🟡 视觉 |
| 标签布局 | **双行**：等级名（大）+ 等级说明（小） | **单行**："五级初级" 连写 | 🔴 结构 |

**调整方案**：
1. 图标 `⚙️` → `🚜`
2. 标签改为双行展示：
   - 第一行：等级名称（"五级"等），font-size 28rpx，font-weight 600
   - 第二行：等级说明（"初级"等），font-size 22rpx，颜色 #888888

数据结构调整：
```
// 原：{ key: 'level_5', name: '五级初级' }
// 改为：{ key: 'level_5', level: '五级', desc: '初级' }
```

### 2.5 分组三：热门考证

| 元素 | 原型图 | 当前代码 | 差异等级 |

### 2.7 底部「完成」按钮（🔴 缺失）

| 元素 | 原型图 | 当前代码 | 差异等级 |
|------|--------|----------|----------|
| 按钮 | 全宽蓝色圆角"完成"，固定底部 | ❌ 不存在（选中即跳转） | 🔴 功能 |

**调整方案**：
1. 新增底部"完成"按钮，固定在页面底部
2. 按钮样式：全宽，蓝色渐变，圆角 48rpx，白色文字 32rpx
3. 交互变更：选中标签不再自动跳转，改为点击"完成"按钮后校验并跳转
4. 未选中时按钮降低透明度表示不可用
