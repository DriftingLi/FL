# 页面标题区居中：专属类名 + 取 h1 档，正文标题不动

- 状态：已采纳（2026-11-08，#2357 实施同批写入）

## 背景

父 spec #2351 把「四个面一套正文刻度」与「页面标题区居中」定在一起：标题 40/56/700/深灰、元信息行与标题同轴、正文内 markdown 标题一律左对齐。落地前章节页与精选页的标题类名（`.chapter-title` / `.article-title`）同时被列表卡片复用（28rpx / 32rpx），挂在这两个名字上的任何规则都会把列表一并转正；子 `<text>` 不继承父样式，抽一个标题区组件也不成立。

## 决定

1. 居中只落详情页实例：新增页面私有类 `.page-heading` / `.page-meta`（实施前全仓零命中），列表卡片继续用旧类名，一个字不改。
2. 不抽标题区组件：`<text>` 不继承父 `text-align`，`styleIsolationVersion: "2"` 下同名类跨文件本就隔离，抽组件只会改宽度语义。
3. 取值全引刻度变量：`$md-size-h1` / `$md-line-h1` / `$md-weight-heading` / `$md-color-text`（40/56/700/深灰）；`text-align: center` 只落 `<text>`，不用父 `view` 的 `align-items: center` 代替。
4. 元信息行补 `justify-content: center` + `flex-wrap: wrap`，换行后逐行仍居中；精选标题保留 `lines: 3` 与 `text-overflow: ellipsis`。
5. 认证三页（登录/注册/找回）不入本轮：其 `.page-title` 已是 40/bold/深灰/居中，只差行高未归一。

## 后果

- 章节页与精选页标题区同轴；论坛不动信息架构、导航栏不动、正文标题恒左对齐。
- 词表须写清「页面标题区含认证三页、行高暂未归一」（#2358 的词条）。
- 守卫二（#2358）按名字层写：`.page-heading` 的居中声明必须存在，`.chapter-title` / `.article-title` 规则里不得出现 `text-align`。

## 不采用的备选

- 直接在旧标题类名上加居中（列表卡片被一并转正）；抽 `<page-heading>` 组件（宽度语义变化 + 子 `<text>` 不继承）；在 `view` 上用 `align-items: center`（uvue 里文字类样式只认 `<text>`，换行后也不居中）。
