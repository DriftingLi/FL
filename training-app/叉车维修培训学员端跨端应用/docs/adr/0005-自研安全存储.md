# Native Secure Storage (No Paid Plugin)

凭据安全存储采用自研 UTS 原生插件方案，而非购买 `austin-secstore` 付费插件（¥29.99~¥799.99）。核心理由：`austin-secstore` 本质是对 iOS Keychain 和 Android Keystore 的 UTS 封装，代码量不大（5 个 API），UTS 可直接调用原生 Kotlin/Swift API，自研成本更低且无外部依赖。

**实现方案**：在项目内创建 `uni_modules/uni-secure-storage/` 插件，`interface.uts` 定义统一接口，`utssdk/app-android/` 调 Android `KeyStore` + AES-GCM 加密后存 `SharedPreferences`，`utssdk/app-ios/` 调 iOS `Security.framework` 的 Keychain API（`kSecClassGenericPassword`）。非 App 平台（H5/小程序）走 `uni.setStorage` 或 `sessionStorage` 降级。

**Considered Options**：
- `austin-secstore` 源码授权版（¥799.99）：功能完整，但引入付费依赖，且维护受制于插件作者
- `austin-secstore` 普通授权版（¥29.99）：不可审查源码，安全敏感场景不可接受
- 服务端存储 + 每次下发：增加网络依赖和后端复杂度，离线场景无法回填
- 自研 UTS 原生插件：免费、可审查、无外部依赖，但需自行维护

**Consequences**：
- 零成本，代码完全可控，安全审计无障碍
- 需自行处理重装清除逻辑（Android 默认清除，iOS 需显式检测）
- `secureStorage.uts` 抽象层保持不变，调用方代码零改动
