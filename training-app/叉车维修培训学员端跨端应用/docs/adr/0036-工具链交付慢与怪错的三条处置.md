# 0036 - 工具链交付慢与怪错的三条处置

> 状态：已生效 ｜ 2026-10-12 立 ｜ 来源：/wayfinder 诊断（落档票 #1657；执行票 #1654 / #1655 / #1656）
> **职责边界**：裁定「完善一个功能整体交付 2–3 小时」的归因与处置——主体是 agent 会话内的反复重试与误判（Q3 口径），不是工具链单点慢；给出三条可落票的处置。
> 不动四门触发面与证据格式（`0008-移动端验收门与证据.md`）；不动 `-i` 串行语义（#1410 裁定，现值记录在 `training-app/叉车维修培训学员端跨端应用/jest.config.unit.js` 文件头）；不动并发与锁纪律（`0011-一键完成的并发与失败语义.md`）。

**① 目标与范围**：grilling（Q1–Q5）收口的诊断三条——**③ 门「卡死」是误读**（全量首跑 pwsh-50 实为 `exit 0` / 83 PASS，pwsh XML 错误流刷屏淹没汇总行造成「看起来失败」；慢是设计内：fake-adb 挂腿 + adb 每调用 2–5 秒预算超时截树 + 分级退避 + `jest.setTimeout` 120–600s + pwsh 每腿 10–30 秒，CI 同款语义）；**② 门自动化桥失败是环境性失败**（DevTools 需 GUI 登录态与「close 后重开项目窗口」，agent 无法伪造；pre-flight quit 清场已随 #1634 落地 bef4f29b；而「环境不可用」处置在仓内零记载）；**误判是最大成本**（慢≠卡死、噪音≠失败、红了盲跑整道门）。本 ADR 裁定三条处置并拆三张执行票，自身只落决策。

**② 选型 + 一句理由**

- **处置一（#1654）③ 门本地快路径**：并行入口（`test:unit:local` 语义，实测 ~60–90s vs 串行 ~236s）接入门流程 + 全量门末尾输出可机检汇总行——成本减半靠并行，「看起来失败」靠机检行从根上消除；CI 与全量门的 `-i` 一字不动。
- **处置二（#1655）② 门 env-blocked 三分**：环境性失败统一一等结果行（`errors=env-blocked reason=<…>`）与「门失败 / 通过」构成三分——agent 今天只能从 publish 文案猜，猜错就盲目重跑；三分让「环境不可用」成为可机检的处置入口（处置 = 转人工 / 改跑不需要 DevTools 的检查，绝不 kill 主程序）。
- **处置三（#1656）判读纪律入 `docs/agents/dev-loop.md`**（blocked by 前两票）：慢≠卡死 / 机检行判读 / 重跑半径（抖动重跑单套件，先例 #1410 chapterNotFoundBehavior A4）三条判据落按需层——误判是会话行为，纠偏住冷启动必读面；判据住脚本与 ADR，dev-loop.md 只指路不复述（分层纪律）。

**③ 明确不做的事**：不改 `-i` 与 `jest.setTimeout`（#1410 裁定维持，慢是设计内）；不把 ③ 门改快去迁就 agent 的耐心——**门是全量的，快路径是本地日常**，两者结果行必须可区分；不伪造 DevTools 登录态或自动化桥——env-blocked 是一等出口，不是要修的 bug；不做 E2E（`0020-端到端测试通道裁决落锁与装配清退.md`）；本 ADR 不写脚本细节（判据住票与脚本，写了必漂）。

**④ 拆分步骤**：#1654 与 #1655 **可并行**（承载面不相交：`scripts/dev-finish.ps1` + `package.json` vs `scripts/mp-weixin-check.ps1` + `scripts/lib/`）；#1656 **在前两票合并后**开工（判读纪律必须引现测的入口与结果行，不引计划中的机制）；三票各自冷启动会话（`docs/agents/issue-dispatch.md`）。

**⑤ 约束**：三票承载面互不重叠（#1656 只碰 `training-app/叉车维修培训学员端跨端应用/docs/agents/dev-loop.md`）；守护必须**断言产物**（结果行 / 汇总行形状）不断言源码片段，新增守护答 `docs/agents/guards.md` 三问；既有语义零回归（`errors=0`、`errors=env reason=port-not-listening`、`-SkipBuild` 成本账）；② 门三条硬前提（全访问权限执行、DevTools 已登录、项目目录唯一名）不放宽。

**⑥ 验收标准**：#1654 / #1655 各自在真实链路绿一次并留产物（快路径与全量门各一跑；env-blocked 现测一条）；#1656 引用的入口、结果行、时间数字全部现测为真且不与 dev-loop.md 既有节重复；三票 PR 的 ③ 门（CI mobile-test）全绿；本 ADR 与票面互引一致。
