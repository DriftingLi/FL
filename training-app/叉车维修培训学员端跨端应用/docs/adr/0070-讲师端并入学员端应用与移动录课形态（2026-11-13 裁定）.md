# 0070 - 讲师端并入学员端应用与移动录课形态（2026-11-13 裁定）

> 状态：已采纳（2026-11-13，#2490）｜来源：地图 #2485 / 规格 `docs/design/20261113-导师移动录课上传-文件库-章节审核规格.md` / 调研 `docs/design/20261113-导师移动端录制能力调研.md`｜**职责边界**：只裁移动端载体、录制形态与上传时机；身份鉴权沿 `0021`/`0022`，分片契约归 #2487，先审后发归 #2488。术语 canonical 是**讲师**（根 `CONTEXT.md`），「导师」为历史别名。

## ① 目标与范围
讲师用手机录课并上传课程视频：录 → 压缩 → 分片上传入库 → 挂接章节。只回答两件事：落在哪个壳里、录制能力边界在哪。

## ② 选型 + 一句理由
- **载体 = 并入学员端 App 作第三登录身份（讲师）**：独立登录页 + 独立页面栈、不进 tabBar（5/5 已满），入口 = 学员登录页底部（镜像 0021/0022）。理由：讲师 <20 人、每人每周 1–3 次，亏不起第二套基座/上架/验收门；Web 无响应式体系且切后台/锁屏录制不可用。
- **录制 = `camera` + `createCameraContext.startRecord/stopRecord` 多段**（每段一个 mp4），不引 UTS 插件（只能 HBuilderX 创建、不支持 cli，与 `build:*` 链冲突）。升级触发条件：实测 `timeout` <10 分钟 / `compressVideo` 压不进 2 GB / 后台上传成硬需求。
- **暂停 = 分段**：官方录像无 pause/resume（`getRecorderManager` 仅音频）；草稿 = 本地段列表（路径/时长/大小/序号），支持续录、整段重录、删段。
- **产物 = 一段一文件、一节多段**：客户端无合并 API，成片合并归服务端转码（未开票）。
- **体积 = 录后 `uni.compressVideo(bitrate≈2500, resolution≈0.75)`**，单文件 ≤2 GB 兜底；录制侧不可控编码，压缩是唯一原生旋钮。
- **上传 = 前台分片**（`getFileSystemManager.read` + `uni.request` 传 `ArrayBuffer`）：队列 + 防息屏 + 断点续传 + 回前台恢复；不做后台上传（无官方能力）。
- **第一阶段范围**：录/压/传 + 文件库列表·改名·删除·挂接章节；章节 Markdown 编辑留在 Web 讲师端。

## ③ 明确不做的事
不做独立讲师 App、Web 响应式录制、H5 讲师端；讲师功能不进小程序端（`0064`）；不做段内剪辑/段合并/后台上传；不重启 ② 门（#2320 已退役）。

## ④ 拆分步骤
1. ADR + 调研笔记入仓（#2490）。2. 讲师身份接线：角色常量、登录页、`loginPathForActiveRole` 第三分支、页面守卫（镜像招聘端，C2「唯一 reLaunch 出口」不动）。3. 录制页：多段 + 段列表草稿。4. 压缩 + 分片上传队列。5. 文件库与挂接章节。6. 页面落 `pages/tutor` 分包（同 `0066`）。

## ⑤ 约束
讲师页仍会进 mp 产物（`0022` 不开创 `pages.json` 条件编译）⇒ 必须切 `pages/tutor` 分包、入口 `#ifndef MP-WEIXIN`；录制切后台即断（`2003009`，iOS 不许后台摄像）；编码器不可选，iOS 默认 HEVC 而 Web 端不是安全默认值；2 GB 硬线下 1080p30 8 Mbps × 30 分钟 ≈1.76 GB。

## ⑥ 验收标准与实测
待实测（实施前置，不得写成已验证）：① `startRecord.timeout` 最大值；② `compressVideo` 产物是否 H.264 且体积达标；③ 切后台/锁屏上传是否中断；④ `<video>` 能否播 `tempVideoPath`。验收：讲师登录 → 录 10 分钟 → 压缩 → 分片上传入库 → 挂接章节 → Web 文件库可见。
