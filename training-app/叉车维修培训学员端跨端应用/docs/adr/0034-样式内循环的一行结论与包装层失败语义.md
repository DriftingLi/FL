# 0034 - 样式内循环的一行结论与包装层失败语义

> 状态：已生效 ｜ 2026-10-05 立，2026-10-07 补三条腿读数 ｜ 来源：#1543（`npm run style:loop`）+ 该票 `/code-review` 自查轮
> **职责边界**：裁定「改完样式后的日常迭代」这一条链的**载体形态**（一条命令、一行结论、日志落盘）与**父/子进程失败语义**。
> 不动四门与证据格式（见 `0008-移动端验收门与证据.md`）；不动锁纪律与并发语义（沿用 `0011-一键完成的并发与失败语义.md` 的 A-3 与锁交接，本条只是它的第二个消费者）。

**① 目标与范围**：样式类改动此前只有两条出口——`dev:finish -Level standard`（把 ④c 整模块编译门 + 契约测试 + 证据生成一起拖进来，且人要读满屏步骤日志），或手工串 `hx:compile-only` → `hx:run` → `capture:device` → `png-diff` 逐条读输出。两种形态在**同一件事**上加价：**上下文膨胀**与**执行很慢**是同一个出口。本 ADR 裁定把它们收成一个进程、收成**一行机检结论** `STYLE_LOOP …`：红 ⇒ 非零退出且行内点名是哪一页变的；绿 ⇒ 零退出。

**② 选型 + 一句理由**

- **承载面 = 终端输出一行，日志仍全量落盘**（`.ci-verify/style-loop.log`，表头绑 head 与 `dirty_files=`）。「会话只读一行」的前提是**一行以外的事实还在磁盘上**，否则这条承诺就成了少留证据的借口。
- **包装层（父）+ 链体（子 `-Inner`）两段**，而不是一个进程把活干完。`lib/hx-busy.ps1` 的 `Wait-HxFree` 在超时/锁被占时是**自己 `exit 2`**（既有并发语义，不许为迁就入口开第二条口径）⇒ 链体内联在父进程里会被它**就地截断**：那一轮既没有结论行也没有日志。分两段后父进程只认「子进程打出了什么 + 退出码是多少」，子进程怎么死的（`exit` / 崩溃 / 被 kill）都拿得出一行结论；判据集中在纯函数 `Resolve-StyleLoopChildOutput`，成对真跑（有行 ⇒ 原样 relay、无行 ⇒ 合成并按红）。
- **判不了 ⇒ 红**（沿用 `lib/screenshot-gate.ps1` 的纪律）：没有改动页面、截图没落盘、没有本轮截图可对比、子进程静默却报 0 —— 一律非零，绝不回退成「无变化」。
- **退出码三分**：`0` 绿 / `1` 判据判出的红（出路是回去改代码）/ `2` 环境不可用（出路是换环境再看）。编译阶段**判红权在 `Ok`，退出码只用来分方向** —— 拿退出码当唯一判据会漏掉「`Ok=false` 但码是陈旧的 0」这一形。
- **`≤200 B` 由参数范围锁死**（`ValidateRange(40, 200)`），不是写在注释里等人遵守；装不下时按「页名收到 1 个 → 日志取末段 → 页名截断 → 整行硬裁剪」收缩，**结论 + 哪一页 + 产物路径**排在尾部之前，所以先掉的是 `pages/shots/reason/secs`。
- **同帧三条腿协议**（2026-10-07 补，取代「隔天复跑」）：判红腿（真改色值）⇒ `-UpdateBaseline` 刷**同帧**基线 ⇒ 绿腿。跨天基线会让「改坏」与「没改」分不开（现测：同树零改动昨天 0.266%、今天 0.919%，阈值 0.5%）——那是**基线卫生**，不是阈值选型。

**③ 明确不做的事**：本入口**不是门，也不改门**——不进 CI、不替代 ①/②/③/④、不改任何门的触发面与归属，门的结论只能由门脚本自己产出。这一条写进**机检行本身**（恒带 `gate=none`），防的是「把内循环的绿色读成门过了」。不做微信小程序自动化截图（#1542 现读：三票 12 次调用 9 次失败，成功的 3 次全部逐页导航被跳过）。不跑契约测试、不跑整模块编译门（那是中循环「每个视觉满意点一次」的活）。不 fork `PixelThreshold`（默认 0.005 与 `dev:finish` 同源）；要收真机噪声动的是 `-IgnoreTopRows`。

**④ 实测**（设备 Redmi `23049RAD8C` / 1080×2400，1 页 `settings`，head `bee02190`，全文与产物见 `docs/verification/tooling/1543/README.md`）：三条腿串行 —— 红腿 `exit=1`、行内 `shot=settings.png`、像素差 **27.122%**；刷基线腿绿；绿腿 `verdict=green phase=done changed=0`、像素差 **0.324%**、链自报 **235 秒**（驱动侧墙钟 237.8 秒）。分段：编译期诊断 `total=66` ⇒ 装机 `total=78 deployed=True` ⇒ 导航 `seconds=83 samples=13 callTimeouts=0` ⇒ 截图 + 像素比。对照件：同设备同页的现读全链路 `dev:finish -Level standard` 实测 **1007 秒**（**10-05 记**，含 151 秒排队等另一会话的锁）。差的 772 秒来自**不做** ④c 整模块编译门、契约测试与证据生成。**串行资源一个没多**：全程只取一把 `Wait-HxFree`（A-3），HBuilderX 调用一律走既有 `hx-run.ps1` / `lib/build-deploy.ps1` / `lib/auto-screenshot.ps1`。残留噪声定位（本地复算，不占设备）：`--ignore-top-rows 0` ⇒ `different=8387 / ratio=0.003236`；`=120` 及以上 ⇒ `different=0` ⇒ **那 0.324% 全部落在顶部 120 行以内**（状态栏一带），第 120 行以下逐像素相同。

**⑤ 约束**

- **工作树纪律**：进临界区前给 `manifest.json` / `pages.json` / `platformConfig.json` 拍**字节**快照，退出时（含异常与 `exit` 路径 —— 实测 PowerShell 的 `finally` 在 `exit` 时仍执行）按字节写回。`lib/build-deploy.ps1` 自己那层还原比的是**文本**、用 `Set-Content` 写回 ⇒ BOM / 行尾变了它看不出来而 git 看得出来；这一层是**兜底**，不是重复。
- **预检没有判红权**：`Get-StyleLoopWorkState` 只看「`pages/` 下有没有改动」，故意取成推导集合的**超集**；读不到 git（非仓库 / git 不可用 / dubious ownership）⇒ **fail-open**。⚠️ 「读不到」必须**显式认退出码**：`$ErrorActionPreference='Stop'` **不会**让原生命令非零退出抛异常（本机实测 pwsh 7.6.6、`$PSNativeCommandUseErrorActionPreference=False`：`git -C <非仓库>` 返回空串 + `$LASTEXITCODE=128`，`catch` 根本不触发）。只写 `catch` = 注释承诺 fail-open、代码走 fail-closed = 谎称没活把人挡在门外。两条 git 调用**分级**：`diff HEAD` 是主判据（失败即读不到 ⇒ fail-open），`origin/master...HEAD` 是补充（`origin/master` 不存在是常态，它的失败不许把干净树拖进 fail-open）。
- **「到了设备」只认 `Deployed`**（设备侧事实相对基线前进），**不认 `Ok`** —— 后者是「调用成立」，`lib/build-deploy.ps1` 的 quick 那一支明写 `Ok=$true / Deployed=$false`。
- **转发实参只许一份**：入口 param 块 → 一张 `$loopOpts` 表 → 同时派生链体入参与子进程命令行，另加「表键必须是链体参数名」的形状自检。手抄清单**漏抄一个不报错**（子进程静默用默认值 ⇒ 人传的 `-IgnoreTopRows 120` 变成 0，判据就不再是人以为的那个）。
- **日志落不了盘时那一行必须改口**（`log=unwritten`），细节走 stderr；一行承诺不因写盘失败而退化成 PowerShell 错误栈。
- **首次运行的基线落盘动作归入口执行**：判定表里 `write-baseline` 那一支只给结论、动作归调用方（`dev-finish.ps1` 步骤 7 同款）；只转述不执行 ⇒ 基线永远为空、每轮都「首次运行」、判据永不咬（同一死循环由 `0008` 的「2026-09-18 修订（`dev:finish` 步骤 7 从空转修成真的）」第 3 条掐掉；⚠️ 别按行号引它——`scripts/lib/screenshot-gate.ps1` 里那句「ADR-0008:419」如今指向的是另一节，0008 一直在长，**行号引用必然漂**，要引就引小节名）。「什么算本轮」**不重写** —— 直接调 `lib/screenshot-gate.ps1` 的 `Select-ThisRunShots`。
- HBuilderX 是单实例串行资源：**绝不 kill** `cli` / 主程序，忙就等、超时 `exit 2`。

**⑥ 验收标准**：守护必须是**行为守护**且断言**产物形状**（那一行的字节数与字段、退出码、还原后的文件 sha256、真跑入口的终端行数），不许用 `expect(src).toContain(源码片段)` 充当 ③ 门证据；自带成对断言（必不红 / 必红各半）。真源现测：`node scripts/classify-guards.mjs` 把 `utils/styleLoopBehavior.test.js` 判为 `[行为]`，单套件 **33** 用例，八组 L/V/W/R/C/D/E/P。E 组一律带 `-Device <不存在序列号>` + `-ProjectDir <临时目录>` ⇒ 在任何机器上跑都不抢 HBuilderX。PR #1561 的 ③ 读数与三条腿产物在仓内可复算。
