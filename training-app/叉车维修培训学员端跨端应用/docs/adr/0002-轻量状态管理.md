# 0002 - 轻量状态管理：不用 Pinia，页面级状态用 Vue 3 reactive

项目不引入 Pinia 或其他全局状态管理库，仅用原生 Vue 3 `ref()` 做状态管理。唯一的全局 store 是 `auth.uts`（登录态），其余领域状态（课程列表、积分余额、论坛数据等）全部在页面组件内用 `ref()` / `computed()` 管理。

选择此方案的原因：（1）uni-app-x (uvue) 编译到 Kotlin 时，Pinia 的 Proxy-based 响应式系统兼容性存疑，保守起见不引入风险；（2）页面级状态随组件销毁自动释放，内存友好；（3）当前项目状态共享需求不大——各页面独立请求数据，没有复杂的跨页面状态同步场景。

代价是页面间共享数据（如积分在论坛页和积分明细页）需要各自请求，无法复用缓存。当前业务量下可接受。
