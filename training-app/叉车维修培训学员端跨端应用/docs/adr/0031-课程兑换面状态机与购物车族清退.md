# 课程兑换面状态机与购物车族清退

> 状态：已裁定（grilling 收敛 + 真机原型取证，2026-09-30）｜来源：「移动端按金额付费改为按积分收费」grilling 会话（问题 1–7 全槌）
> 原型：分支 `prototype/points-redeem-cta`（throwaway 留档，out of main；截图在其 `prototype/points-redeem-cta/shots/`，真机 marble/arm64-v8a 出证）
> 关联：根仓库 `CONTEXT.md`「权益」「积分商城」词条；移动端 ADR-0009（专业版形态先例）、0016（①b 能力面判据）；根仓库 ADR-0062（权益读门禁，编号体系属根仓库）

## 背景与定性

「按金额付费」经查**从未存在过**：`¥` 只是三处 UI 残留（mall 价格行接的是后端从不下发的 `price` 字段、恒渲染「免费」；dashboard 课程区是静态 mock 且拿 mock id 跳真实详情页；「报名」只有 toast）。后端与 Web 端的积分契约（`course.points_price` + `POST /points/shop/course/:id/redeem` + 详情投影 `entitled`）早已建好。故本票定性为**移动端接入既有积分契约**（tracer bullet：看到价 → 兑换 → 能学），不是计费模型变更，不引入也不残留任何金额支付。

## 决策

1. **兑换面单点归 `course-detail`**。CTA 四态由 `(points_price, entitled, balance)` 派生：免费（null/0）→「开始学习」；未拥有余额足 →「N 积分兑换」；未拥有余额不足 → 同 CTA + 装饰提示（见 3）；已拥有 → 兑换 UI 消失、回归现行为（兑换面**不常驻**）。
2. **确认环节不可绕过**：`uni.showModal`「该课程需 N 积分解锁，确认兑换？」。理由：积分是挣来的真资产、兑换终身不可退（redeem 管线无退单），误触即扣。
3. **余额预判＝装饰层，永不拦截 CTA**：余额不足时 CTA 下一行「余额不足 · 还差 N 分 · 去赚积分」（可点直达任务中心）。口径照抄 ADR-0009 时代的 `useAiPro.uts` 头注——「预判只为提示口径，真正的判定在服务端兑换管线」。余额读不到（未接/读失败）⇒ 提示整体缺席、干净降级为纯事后，不得报错挡道。
4. **成功后重拉详情取服务端 `entitled`**，禁内存抹 `points_price` 当已解锁（根仓库 `CourseList.vue` #475 血账同判据；`CONTEXT.md`「权益」_Avoid_ 点名反模式）。
5. **`chapter-view` 未解锁 404 支不内联兑换**：「去解锁」跳回 detail 兑换面。判据：#1268 已定「未解锁」与「不存在」返回同一个 404、不泄漏存在性 ⇒ 内联兑换等于可能对一门并不存在的章节提供兑换入口，且违背决策 1 的单点归属。
6. **购物车族一次性删除**：数量选择器、🛒 与 `onCart()`、本地 `quantity` 字段、「已有 N 人参与学习」行。判据：兑换是「每人每 SKU 终身一个事件」（幂等键含主体、`HasEntitlement` 按人判存在），数量与销量在积分域**永无消费者**；且价格行接线（`price > 0` 复活）会连带激活这些死 UI——接线处必须同时处置无数据源的邻居（学员端列表 `student_count` 后端根本不发，恒 0 是假信号）。
7. **「N 积分 / 免费」价格渲染收敛为共享件**，mall 与 dashboard 课程区同函数消费；dashboard 课程区接真实 `GET /courses`（只换数据源，Tab/筛选选中态维持纯视觉现状）。

## 明确不做

- 电商话术文案清扫（「热销」「必买清单」「参与学习」措辞）另计一票（grilling 问题 2 裁定）。
- 学员端列表开 `WithStudentCount`（API 面扩张，若做应叫「N 人在学」并随文案票另论）。
- 实物商城/订单域——真要建从新域长，不在课程货架养死代码。

## 否决的备选

- **纯事后（a）**：首屏与「买得起」格逐像素同形，明知不足却藏到确认框之后才驳回——丢弃手里已有信息，且「先举手表态再被当众驳回」羞辱感最高。仅保留为余额拿不到时的降级兜底。
- **cost-block 余额常显（c）**：为一件事实铺一整个卡片，精确缺口「不用点就挨」；其数字被吸收进决策 3 的提示文案，形态整体否决。
- **只清文案不建兑换面**：学员撞见看得见价、无处可花的死胡同。
