# 0064 - 小程序端发布范围仅学员端与唯一发行路径

> 状态：已采纳（2026-11-11，#2416 实施同批写入）｜来源：规格 #2359｜**职责边界**：只裁小程序端**发布范围**与**发行路径**，不改 0021/0022 的身份、鉴权与页面形态结论，不动后端。

## ① 目标与范围
把已经发生的事实裁定下来：**小程序端只发布学员端**。覆盖 `0021` ②「平台面 = 仅 Android/iOS」与 ③「不做小程序端」（其「不做分包」的理由随之失效，本轮仍不做分包），以及 `0022` ②「小程序端不发布」、③「不做小程序端」（⑤ 那条「仍会把招聘者页面打进产物」的代价不变，只是理由改为招聘端非发布必需）——两套事实并存时，下一个人会照旧 ADR 删掉本次加的配置。

## ② 选型 + 一句理由
- **发布范围 = 仅学员端**：招聘端在小程序端**非发布必需**，学员端**必须发布且必须可用**——这是将来任何降级/裁切时先动谁的判据。
- **唯一发行路径**：`npm run build:mp-weixin-buildonly`（HBuilderX `cli publish mp-weixin`）→ 上传 `unpackage/dist/build/mp-weixin`（项目根相对，票面简称 `dist/build/mp-weixin`），不是未压缩的 dev 产物 `unpackage/dist/dev/mp-weixin`；不靠开发者工具手勾、不靠构建后补写脚本。
- **本轮不做分包**：不切普通分包、不配 `preloadRule`、不动 `pages.json` 页面归属。

## ③ 明确不做的事
- 不做支付宝小程序端；本轮不把招聘端页面移出主包；不重启 ② 微信开发者工具门（#2320 已退役）。
- 不新增发布文档、不新增构建后补写脚本；不改 `0022` 的源码级 `#ifndef MP-WEIXIN` 守卫与招聘者工作区源码形态。

## ④ 拆分步骤
1. 本 ADR 落库（编号取执行时 `docs/adr` 最大号 + 1）。2. `0021` / `0022` 相应段落各加一行指向本 ADR 的注记（只加注，不删历史结论）。3. 移动端 `AGENTS.md` 八步执行单第 ⑤ 行补一句上传目录指针。

## ⑤ 约束
- 小程序端产物仍会打包招聘端页面（源码级守卫 + 招聘端不发布），这是已接受的代价，不是待修缺陷。
- 1.5 M 建议线的权威读数是上传面板，不是本地产物字节（`minified` 是上传时压缩）；若上传后仍 >1.5 M，降级动作 = 只把招聘端那 72 KB 切出主包（规格 #2359 维护者原话），学员端页面必须保留且可用。

## ⑥ 验收标准
本 ADR 六段齐、≤25 行；`0021` / `0022` 各有一行指向本 ADR 的注记；`npm run build:mp-weixin-buildonly` 产出 `unpackage/dist/build/mp-weixin` 且上传该目录；学员端在小程序端可用，招聘端缺失不构成发布阻塞。
