# 0003 - 手动 build*() 函数做 JSON→类型映射

每个 API 模块都编写 `build*()` 函数，将后端返回的 `UTSJSONObject` 逐字段手动赋值给前端类型定义，而非使用 `as` 类型断言或运行时类型映射。

选择此方案的原因：UTS（uni-app-x 的 TypeScript 变体）编译到 Kotlin 后，`as` 类型断言仅是编译时检查，不做运行时类型转换。直接将 `UTSJSONObject` 强转为自定义类型会导致 Android/iOS 原生端崩溃。因此只能手动逐字段赋值，确保每个字段都经过类型安全的处理。

此模式的代价是代码量较大（每个 API 响应都需要一个 `build*()` 函数），但保证了原生端的类型安全。Web 端（H5）虽然支持动态类型，但为保持代码一致性，统一使用此模式。
