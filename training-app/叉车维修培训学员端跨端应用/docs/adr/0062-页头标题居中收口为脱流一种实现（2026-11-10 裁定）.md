# 页头标题居中收口为脱流一种实现

- 状态：已采纳（2026-11-10，#2402 实施同批写入）

## 背景

`--center`（流内居中）不是居中：右槽为让开小程序胶囊带 `width: 750 − capsuleLeft` 加大段 `margin-right`，流内标题只能在「左槽 → 右槽」剩余宽度里居中，标题中心 ≈ (W + L − R) / 2，实测左移约 190rpx。九个页头受影响（我的 / 课程 / 学员论坛 / 工作台 / 招聘端五页），全部传 `:left-icon="''"`；真居中形态 `--floating-center` 早已存在，却只由 `centerTitle` 触发、全仓仅 AI 助手在用。约定面 `docs/ui-spec.md` 早写「标题：居中」，与实现漂移。

## 决定

1. 居中判定收敛到一处 `titleFloating`：`centerTitle` 直通 **或**「左槽空置且有标题」自动触发。
2. 删除 `--center` 形态类及其分支 —— 居中只剩脱流一种写法，杜绝第二份实现复活。
3. 不 fork 样式：复用 `--floating-center`（left 88 / width 574 / 两侧槽 `--front` 抬层），几何一个数不改。
4. 调用方零改动：九个页头自动受益；`centerTitle` 降级为「左槽有字也要居中」的覆盖开关。
5. 守护改判 `titleFloating`：两侧槽抬层数 2、自动分支存在、非空标题守卫、`--center` 防复活。

## 后果

- 页头标题字面居中；左对齐形态（左槽有返回箭头）不受影响。无标题时不脱流，避免凭空长出透明点击区。
- 代价一：脱流块命中区 574×88，左入口（工作台证件切换）点击面比文字宽 —— 仍在页头内、不高频。
- 代价二（待真机复验）：绝对定位包含块若为 `.nav-bar-body` 的 **padding box** 而非 border box，标题中心为 399rpx、`left` 应改 64rpx；本机无设备实测，暂沿用 AI 助手已上线几何。
- 与 `0057`（页面标题区居中）分两层：本裁定只管导航栏，正文标题不动。

## 不采用的备选

- 逐页加 `centerTitle`（九个调用方各改一次，且以后新页仍偏左）；镜像左槽宽度到右槽（388+388 > 702 内容盒，flex 收缩把对称吃掉）；`left + right` 双锚点铺满（本仓零先例，且铺满会盖左槽 ☰）；`left: 50%` + `translateX(-50%)`（百分比 transform 原生端未验证）。
