# 回答能力徽章与耗时：两路同源、归一在纯函数、渲染在气泡下方

- 状态：已采纳（2026-11-09，#2361 决策收口；实施随后同批提交）

## 背景

后端自 #2245 起把 `DiagnosisMeta`（badges + elapsed）随 `done` 事件下发并落库，回看走 `AIChatMessageDTO.meta`；网页版已展示，手机端按 #2245 决定「一行不改也不读元数据」⇒ 三处空档：`useAiChat` 的 `onDone` 只读 `content`、`buildSessionMessage` 不读 `meta`、气泡无徽章/耗时渲染件。难点是**两路形状不对称**：当轮 `DiagnosisMeta` 两字段带 `omitempty`（可能整键缺席），回看 `AIChatMessageMeta` 键常在且 `badges` 恒数组（nil 归一成 `[]`）。

## 决定

1. `types/ai.uts` 新增 `AiDiagnosisBadge{name,emoji,cls}` 与 `AiDiagnosisMeta{badges?,elapsed?}`，给 `AiChatMessage` 与 `AiSessionMessage` 各加 `meta ?: AiDiagnosisMeta` —— **当轮与回看落到同一消息字段**，后续渲染只有一条路。
2. 解析单点：`api/aiAssistant.uts#parseDiagnosisMeta(raw)` 被「回看 `buildSessionMessage`」与「当轮 `onDone`」**共用**，产出恒定形状（`badges` 恒数组、`elapsed` 恒数值），把上面那处不对称吸收在入口。行内不判 null：raw 为 null 返 null，调用方「有值才写字段」（不写 null —— #2328 事故链）。
3. 三态归一下沉纯函数 `utils/aiDiagnosisMeta.uts#metaViewOf`：出 `{visible,badges,elapsedText}`，`visible = badges.length > 0 || elapsedText.length > 0`（空数组 / 只有耗时 / 全空各成一态）。耗时文案 `耗时 N.N 秒` 由 `elapsedLabelOf` 组装，`elapsed <= 0` 返空串；残条（name 与 emoji 都空）丢弃。判据是**真执行**的行为测试，不是读源码的接线守护（票面 AC⑤）。
4. 渲染件 `components/ai-chat/ai-chat-badges.uvue` = 徽章行 + 耗时脚注同一个件，位置在气泡闭合之后、来源折叠件之前（票面 AC「回答下方」）。件内按 `metaView.visible` 自判 ⇒ meta 为 null 不出空壳（AC③）。
5. 徽章三字段**原样消费**、不另造词表（AC④）：`cls` 只进渲染 key 的视觉提示位，不参与语义判定、不驱动配色（对齐 web `DiagnosisBadges.vue`）；`badgeLabelOf` 只做「emoji/name 互相缺省」的拼接，不做词表映射。
6. 可空对象 prop（`meta ?: AiDiagnosisMeta`）**不进 withDefaults**，走「包装函数判空退化 + `as` 强转」的既有形态（`ai-chat-diagnosis-guide.uvue` 的 `state` 先例）；气泡侧以 `messageMeta` computed 归一（null 原样返回），模板不对 `meta` 成员直取。
7. 耗时与 #2298「已等 N 秒」等待态**互不相干**：一个在回答后、一个在等待中；`trace` 字段客户端不读、不展示。

## 后果

- 后端零改动、库表零改动；非诊断功能 `done` 载荷是 `null` ⇒ 走 `data == null` 早退，不产生空 meta。
- 当轮与回看共用解析器与归一函数，套件直接断言「同一条消息两路得到的 `metaViewOf` 结果 `toEqual`」（AC②）。
- `api/aiAssistant.uts` 本次**未新增运行期 import**（只用既有 `toStr`/`toNumber`）⇒ 五个 `loadUts` API 套件的 bindings 不动；`useAiChat.uts` 新增一个运行期 import ⇒ `utils/aiDoneContentBehavior.test.js` 的 chat bindings 必须同批补键（fail-closed）。
- 新增 uvue 必须在 `utils/modules.js` 的 `MODULES['ai-assistant'].files` 补一行，否则 `modulesDeclarationContract` E2 判红。

## 不采用的备选

- 组件直吃 wire 形状、在模板里做三态判定：uvue 模板对可空成员直取正是 #2328 的缝（`.length` 落在 null 上），且三态逻辑将无法被真执行断言。
- 在 api 与 composable 各写一份「meta → 视图」映射：两路必然漂移，正是 AC②「不是两套映射」要防的；后端侧 `parseDiagnosisSources` 的单点注释已立下同一条规矩。
- 抄 web 的视觉位置（徽章在气泡上方）与 cls 配色：票面 AC 明写「回答下方」，cls 驱动配色需要客户端词表副本，违反 AC④。
