**② 豁免的正式开放未裁定**——须影子数据经维护者审阅后另行落地（见决策 7）。影子之前，一切验收门行为与现状完全一致。

- **承接 / 覆盖**：**修订** `training-app/叉车维修培训学员端跨端应用/docs/adr/0043-真机门降级常态化与发版冒烟（2026-10-23 裁定）.md` 决策 3（「每个运行时面 PR 必跑 ②」→ 按档触发，生效时点=豁免转正）与其决策 8 的「低风险分层退役」——**不复活** 0008:116-120 的逐文件白名单载体，另立「粗粒度模块清单 + 机器核身」新形态。**不动**：0049（A1 证据形态）、0046（本地子集）、0043 决策 1/2（①a 发版冒烟）、0020（E2E 落锁）、Worktree 闸门与 HBuilderX 锁纪律、③ CI 两腿、④ 编译门。
- **编号说明**：本文件属**移动端** ADR 编号体系；裸引「ADR-0052」须写全路径。

## ① 目标与范围

**目标 = 速度**。实测成本结构：常态 12–17 分钟/PR 的墙钟集中在 ②（半自动 devtools 门 + 本机工具单实例锁）与 ④；③ 全量在 CI 不占墙钟；证据已随 A1 降到正文一行。故提速的唯一大刀是 ② 的触发面——**本轮改动范围只限 ②**（维护者明示约束）。

三条锚点事实（2026-10-31 现测，非回忆）：

1. **三端测试纪律一致**：100-PR 合并审计（附录 A）——后端 10/10 带测试、前端逻辑改动全带 spec（缺测仅纯 `.vue` 模板批次、且已由 #2157 一次性回补）、移动端 40/40 带测试（测试/源码比 0.55 全仓最密）。「别的端快是因为不写测试」**不成立**；审计证明的是纪律面无可减，**不直接证明 ② 可取消**（维护者裁定语，本 ADR 遵此把「可否取消」交给影子数据）。
2. **CI 零编译**：`.github/workflows` 全目录 grep `kotlin|mp-weixin|HBuilderX|hx:|build:` 零命中；`mobile-test` 六个 jest 片只跑 `utils/**`，`loadUts` 为 Babel 剥型执行（`utils/utsHarness.js:115-141`），非编译器 ⇒ ④ 是唯一合并前编译检查，**不可减**；② 无法搬进 CI（HBuilderX 本机授权，无 headless 路径）。
3. **② 的机检现状**：`needs2` 只认 MP-WEIXIN 面（`gate-validator.mjs:116-134`），纯 `.uvue/.uts` 靠纪律（0043 决策 3 如实登记的脆弱性）。分档把这条散文纪律换成机器判据，方向与 0043 一致，不是绕过它。

## ② 决策

1. **三档**：全门档 / 模板减配档 / 逻辑减配档。**逻辑减配档初期关闭**（`logicLiteTierOpen=false`），开启前置 = 模块级测试覆盖图建立，届时单独裁定。模板减配档**只开放经严格识别的低风险模板修改**（判据见决策 3）。
2. **唯一可执行数据源**：核心名单只存 `.github/scripts/lib/mobile-gate-core-list.json` 一份；`gate-validator.mjs` 读它；本 ADR 与一切文档**不维护第二份名单**（内容以数据文件为准，防 #1845-#1848 式两口径并存）。名单确认前（决策 7 之前），校验器对所有运行时面 PR 维持现状行为。
3. **`.uvue` 归类不凭后缀、只按 diff 内容三级阶梯**（阶梯兜底永远向上）：改动含 `<script>` 块、组件标签增删、数据/事件绑定语法（`:`/`@`/`v-model`）→ **全门**；DOM 结构、布局属性、安全区、导航栏属性 → **② 定向**（`coverage=changed:N`，不整免）；纯文案与非布局样式值 → **模板减配（免 ②）**；CSS 类名改动须证明目标类不含布局属性，证不动 → 升 ② 定向。
4. **全局升全门判据**（不确定一律保守）：混档 PR（核心与非核心同 PR→整体全门，不禁止混档）；文件 rename/delete/move；`components|api|stores|composables|utils|uni_modules|config|constants|i18n|types` 目录、`App.uvue`、`main.uts` 任何改动；三份 json；diff 增删 `#if(n)def` 行；**新增页面未入清单默认全门（fail-closed）**。
5. **机器核身**：PR 正文声明档位，校验器拿改动路径 × 名单 × diff 判据核对，声明与事实不符判红；判据落 `gate-validator.mjs`，配守护用例覆盖：路径归类、混档升级、核心依赖传播、声明不符、测试发现异常、合法 `planned=0`（各至少一例）。
6. **`planned=0` 双证链**：合法 = 同一读数行 `planned=0 discovered=N` 且 N>0（discovered 由两腿 config 现测 `--listTests` 证明发现过程健康）+ 改动文件→套件映射机器算得为空。**发现异常、路径匹配错、测试配置失效一律判红**——延续 #1144「静默 0 套件长得像绿」的 fail-closed 血账。
7. **四波实施 + 影子审阅门**：波 1 = 本 ADR + 数据文件（纯新增，零行为变化，#2170）；波 2 = 校验器分档判据与守护用例，**影子模式**（只记录：分档结果、误分类、② 本可抓到的问题——不改判、不进正文要求）；波 3a = 影子数据报告（分档分布 / 误分类清单 / 设备门命中账 / 潜在漏检估计）交维护者审阅；**波 3b = ② 豁免转正**，仅在 3a 批准后执行，届时翻转数据文件 `exemptionActive=true` 并回写本 ADR 实施回记；波 4 = 文档回写（移动端 AGENTS.md、根 AGENTS.md、checks.md）。**波 4 之前不回写任何常驻文档**——影子期「文档说分档、机器按旧门」正是 #1845 复盘的禁区。
8. **交易性能力登记**：移动端现测无支付代码（`requestPayment` 零命中）；积分商城与 mall 按维护者裁定入核心档（积分兑换具交易性质）。未来引入支付/兑换类交易能力时，**必须先把对应路径加入数据文件名单，再开发**。

## ③ 后果

- **正**（豁免转正后）：模板档 PR 免 ② 常态省 8–12 分钟/PR 与锁排队；`.uvue` 纪律判据机器化，比现状（散文+荣誉制）更严而非更松；影子期本身产出「② 到底抓到过什么」的第一份账。
- **负 / 风险**：模板档的渲染回归落点 = ② 定向线、④ 编译面、发版冒烟与用户反馈——② 整免的那一半风险由 3a 审阅把关；名单有维护面（新页默认全门 + 守护用例兜漂移）；影子与分档实现是先行成本，波 2/3a 无直接收益。
- **可逆性**：3a 若判误分类率高或漏检不可接受，弃 3b、本 ADR 状态行改「分档设计存档、豁免未开放」即可，机制无残留。
