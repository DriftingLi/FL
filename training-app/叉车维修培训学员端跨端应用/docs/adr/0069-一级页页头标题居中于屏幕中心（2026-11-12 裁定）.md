# 一级页页头标题居中于屏幕中心：侧槽脱流 + 右槽清空

- 状态：已采纳（2026-11-12，#2479 实施同批写入；改判 `0062` 的居中几何取向与 `0067` 决定 4）

## 背景

`0067` 把居中定义为「**可用空间**的中心」：标题块流内 `flex: 1`，而空置的右槽仍在流内吃 `rightSlotStyle` 的胶囊让位（典型 194rpx）⇒ 一级页标题中心落到约 268rpx，比屏幕中心（375rpx，屏宽 750）左移 107rpx。维护者判据（2026-11-12）：**右侧没有动作 = 标题直接居中**；一级页的页级动作（工作台 🔔、AI 助手 ⋯、论坛 ✉️）按 `0067` 决定 4 落左槽，标题又被左槽推位。

## 决定

1. 一级页（`left-icon` 空 = 无返回箭头）标题**居中于屏幕中心**；二级页整枝不动（仍是可用空间中心，另票收）。
2. 居中形态两侧槽**脱流**：`position: absolute`，左 `left: 24rpx` / 右 `right: 24rpx`，包含块是 `.nav-bar-body`（加 `position: relative`）⇒ 空右槽的让位宽度不再参与标题块几何。绝对定位按绘制顺序盖在静态标题块之上 ⇒ 左槽动作照旧可点，不加 `z-index`。
3. 标题块两端 **48rpx 对称留白**（必须用 `margin` —— 测试禁数值 `padding-right`）：内容盒 [24,726] 内缩到文字带 [72,678]，中心恒 375rpx，与侧槽内容无关。
4. 一级页右槽一律为空：AI 助手 ⋯（右抽屉唯一可见入口，`0063` 决定 4）下沉 `#toolbar` 第二行（页面 API 仍是 `menuClick`）；工作台 🔔 移出页头（论坛 / 个人中心 / 简历三处入口仍在）。左槽动作原地保留（论坛 ✉️、AI 助手 ☰）。
5. 删 `#1677` 的「左槽空置时标题代发 leftClick」隐式规则：标题点击**一律** `emit('titleClick')`，工作台用 `@title-click` 接线。
6. 契约改判：`appNavBarLeftEntryContract` 钉 titleClick / 禁代发 / 禁守卫 + 居中几何（侧槽脱流、48rpx 对称留白、`.nav-bar-body` relative）；`aiChatDrawerContract` 的右入口锚点从右槽改 `#toolbar`。

## 后果

- 一级页标题中心恒 375rpx；标题可用宽 440 → 654rpx（约 24 → 36 汉字）。二级页仍是可用空间中心（右槽有动作时偏左）。
- AI 助手页多一行 88rpx 工具栏（`showToolbar` 恒真，⋯ 常驻 ⇒ 不随状态出现/消失）；页级动作不再与标题抢同一行。
- 几何保证换代：`0067` 靠「让位」保证标题不碰右槽，一级页改由「**右槽必须为空**」保证 —— 一级页新加右槽动作会被契约判红。
- `0067` 决定 4 收窄为「左槽动作保留；右槽清空」。

## 不采用的备选

- 免胶囊让位 / 镜像右槽 / 不渲染空右槽（三种横向微调，原型实测）：中心最多到 365rpx 仍非屏幕中心，且是宽度换宽度（440 → 634rpx）。
- 页头整行下移到胶囊之下（维护者先提的方向）：全站 53 页页头各长 112rpx，且标题仍非屏幕中心。
- 标题块自身脱流（`left`/`right` 双锚点）：绝对定位块盖在静态左槽之上，☰ / ✉️ 的点击被标题抢走（`0067` 已明确不需要这套）。
