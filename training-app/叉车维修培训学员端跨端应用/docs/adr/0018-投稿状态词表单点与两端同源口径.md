# 0018 - 投稿状态词表单点与「两端同源」口径

**状态**：已接受（2026-09-17，issue #1108；根仓 `ADR-0056` §8「状态词表单点」的移动端落点）

## ① 目标与范围

移动端「我的上传」（`pages/resources/my-uploads.uvue`）的投稿状态文案/配色原先内联在页面里，
且与 Web 端**同源契约、两种词**——`pending`「待审核」vs「审核中」、`rejected`「未通过」vs「已驳回」。
本决策把判定收进 `utils/contributionStatus.uts` 一份，并按「描述状态事实」统一取词。
范围只有移动端呈现面：后端契约、Web 端词表、页面观感都不动。

## ② 选型 + 一句理由

| 决策 | 一句话理由 |
| --- | --- |
| 判定落点 `utils/contributionStatus.uts` | 与根仓 #1103 的 descriptor 同形（输入 status、输出描述子），消费面只做投影；`utils/forumDisplay.uts` 已是本仓「文案单点」先例 |
| 表形态 = 行数组 `ContributionStatusDescriptor[]` + 线性查找 | UTS 没有编译期穷尽 `Record`（联合字面量不能运行时强转），`Map.get` 又返回可空 ⇒ 行数组是两边都不踩的形态 |
| 文案**对齐 Web**，不另立移动端口径 | 同一个后端契约在两端出现两种词是漂移，不是端内差异；`pending`「审核中」在移动端本就另有先例（`personal-info.uvue` 的资料待审徽标） |
| 穷尽性靠 `utils/contributionStatusContract.test.js` 三重对账 | 移动端拿不到编译期穷尽，**测试期暴露**是唯一可落地的「漏值必红」；根仓同款做法见 `frontend/src/utils/__tests__/statusWords.spec.ts` |

## ③ 明确不做的事

- **不改后端、不改 Web**：投稿域在 Web 侧仍是 `ContributionTab.vue` 的 `STATUS_LABEL`（#1103 只落了联络授权 / 投递两个 descriptor）。把投稿域也收编成 descriptor 是根仓的事——本票只回报，不代做。
- **不动图标语义**：`withdrawn` / `archived` 沿用 🕐，色值与图标逐字保留——本次只统一文案，不做观感改版。
- **不改未知取值兜底**：认不出的状态仍按待审观感呈现（旧行为）；「新增了状态却忘加行」由对账锁①负责暴露，不靠兜底静默糊过去。

## ④ 拆分步骤

1. `utils/contributionStatus.uts`：值域 + descriptor 行表 + `describeContributionStatus`（唯一判定处）。
2. `pages/resources/my-uploads.uvue`：四个内联判定换成薄包装投影（守护规则 S：模板不可直调 import 函数），模板结构零改动。
3. `utils/contributionStatusContract.test.js`：单点 / 对账锁①（对 Go 常量表）/ 对账锁②（对 Web 词表）/ 消费面 / 零内联 / **锁自检**六组；同步更新 `utils/resourcesContract.test.js` 的状态徽标断言。
4. `api/contribution.uts` 头部注释改为「文案判定不在本文件」，消掉第二份口径。

## ⑤ 约束（不能动的）

- **uni-app-x / UTS**：入参保持 `string`（联合字面量不能用于运行时强转）；不引入 `Record` 对象字面量与可空 `Map.get`；行形态（单行五字段 + `as` 标注）是锁的判据，改形态要同步改锁。
- **行为面**：除两条漂移文案外不得有可见变化（色值、图标、模板结构、分页与失败态一律不动）。
- **`pages.json` / `manifest.json` / `platformConfig.json` 一行不动**（不改路由、不加页面）。
- 两端同源锁**不许删**：Web 侧收编成 descriptor 时把锁指到新单点，删锁等于退回漂移。

## ⑥ 验收标准

- `npm run test:unit` 全绿（含本票新增的六组契约）。
- 锁自检成立：合成「漏一个取值」「文案漂移」「重新内联」「行形态改散」四种源，锁必须报红。
- 取值集合 == 后端 `service.ContributionStatus*`；五个 label == Web `STATUS_LABEL`——且这两条由锁**持续**维持，不是一次性人工比对。
