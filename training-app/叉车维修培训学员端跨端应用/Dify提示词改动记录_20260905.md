# Dify 提示词与模型参数改动记录

> 日期：2026-09-05
> 应用：叉车维修培训助手（dify.gccsmile.com）

---

## 改动一：系统提示词 - 检索规则第 3 条

**位置：** 工作室 → 应用 → 提示词 → 系统提示词 → 检索规则第 3 条

**改动前：**
> 3. 不同品牌的同名故障码含义可能完全不同，必须区分

**改动后：**
> 3. 不同品牌的同名故障码含义可能完全不同，必须区分；同品牌内不同型号系列的技术资料可互通使用

**目的：** 防止模型在 8FD vs 8FG 等同一品牌内不同型号的手册之间反复自我辩论，直接允许互通使用，节省推理时间。

---

## 改动二：模型参数 - max_tokens

**位置：** 工作室 → 应用 → 提示词 → 模型设置 → max_tokens（最大回复长度）

**建议值：** 4096 或 8192（取决于模型支持的上限，qwen3-kb 支持 8192）

**当前问题：** 模型思考链过长（约 3000 tokens），而 max_tokens 设置过低导致输出在生成答案时被截断，用户只看到思考过程看不到最终回答。

**目的：** 给模型的最终回答留出足够的 token 空间，确保包含完整文字 + 图片链接。

---

## 背景说明

模型在回答「Toyota 8FD 故障码 41-1」时，检索命中的是 8FG 系列手册（8FD 的故障诊断手册未入库）。由于提示词之前要求"必须区分"品牌型号，模型花费大量 tokens 自我辩论 8FD 与 8FG 的关系，导致：
1. 推理时间长达 238 秒（8.59 tokens/s）
2. 思考链吃光 token 预算，最终回答被截断
3. 用户只看到思考过程，看不到答案

改动一和改动二配合解决这个问题：改动一让模型不再纠结型号匹配，改动二给回答留出空间。
