五步链路

#步骤发生了什么怎么自己验证
1名册注入available_skills 名单（名+摘要）进上下文；注明「摘要不等于指令」开新会话看系统提示
2点名加载/名字 → 扫描根按名命中 → SKILL.md 全文进 skill_content看你消息下方的 skill_instructions 块
3按图施工模型按指令调工具（read / write / pwsh / grep / web_fetch / 子代理…）看会话工具调用轨迹
4落盘状态产出写进工作区文件；技能记忆 = 文件不是聊天ls MISSION.md learning-records/
5下次续读新会话先读盘上文件恢复进度新会话直接问「读 MISSION 告诉我学什么」
