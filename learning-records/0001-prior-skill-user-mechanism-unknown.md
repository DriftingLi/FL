# 用户先验：会用 /命令，不懂技能执行机制

用户自述「只用过，不懂原理」（首次会话四问），深度为：能触发技能（用过 /teach 等），但不知道 SKILL.md 如何被扫描、注入、执行，也不清楚工具由谁提供；主战场是 uniapp-x 学员端。同时自述「不确定验收门验了有没有用」——这是疑虑，不是已证伪，别当成他已认定门无效。

## Evidence
- 首次会话的结构化四问选择：mission=弄懂原理就好 / 痛点=不确定验了有没有用 / 移动端含义=技能服务 uniapp-x 项目 / 先验=只用过不懂原理。

## Implications
- ZPD 起点 = 机制层：第 1 课直接拆「一次 /命令的执行链路」，跳过「怎么用技能」的用法层。
- 后续课程顺序：机制（LR-0001）→ 验证层有哪些、各自判据 → 人工门有没有用（用本仓 ADR/血账回答，不空谈）。
- 教学语言中文、课短、可现测。
