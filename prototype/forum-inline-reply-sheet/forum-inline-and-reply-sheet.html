发现实测证据要回写给 ADR / 票一 AC 的东西

      

        ⑩-2 的分词器必须递归，单趟扁平匹配会漏
        **粗体里有 [链接](…) 和 `码`** → v1 产出一个粗体 run，其 text 里**原样带着** [链接](…) 与反引号（INV-6）
        markdownInline.uts 的 run 需要 kids（嵌套子 run），否则「粗体里套链接」正好把 ⑥-1 打破 —— 而论坛帖里这是常见写法
      

      

        ⑥-1 的判据对象是 run 的叶子文字，不是拼接后的整段
        跨 run 拼接时，代码内容 `a**b` 与远处一个裸 ** 会被成对正则连成一次误报（INV-1 首轮假红）
        票一 AC 与 ③ 门用例都应写成「逐 run 断言」；行为守护若按整段 toContain 判会既假红又漏判
      

      

        现状正则会「吃掉」不成对记号与词内下划线的字符（既有缺陷，非 ⑩ 引入）
        2 * 3 = 6，* 是乘号 → 现状产物 2  3 = 6， 是乘号（星号被吃）；a_b_c → abc
        ⑩ 之后这族缺陷会从「静默丢字符」升级成「可见错斜体」⇒ 分词器要带 flanking 约束；代价是 ⑩-5「产物逐字不变」**不成立**
      

      

        ⑩-5 的正确落点：摘要与渲染共用同一次分词的叶子
        投影改为取 runs 叶子后，6 类源串产物变化，逐条都是「不再丢字符 / 不再漏残括号 / 不再误剥代码内容」（INV-2 修复集）
        把 ADR 那句改成「摘要产物只允许等于修复集的变化，其余逐字不变」，并同步 #1273 那条「预览不含星号」判据（裸星号现在会合法出现在预览里）
      

      

        ⑩-3 零形状变更站得住
        有序列表落 list.level=1、无序 0；块字段仍只有 type/level/text/items（INV-8）
        血账（自定义类型数组字段被 UTS 改名）射程内一条都不碰 —— 这条可以照 ⑩-3 落
      

      

        ⑩-6 零回归在「分叉只在 hasMember(inline) 时生效」下成立
        chapter / featured 全部源串在 fork 开关两侧 JSON 完全相同（INV-3）；块结构也相同（INV-3b）
        实现纪律：分叉闸门只问 hasMember(MEMBER_INLINE)，不要顺手把新分词器接进章节/精选的投影（INV-10 实测本语料上二次剥是幂等的 ⇒ 风险低但不是零，别拿它当许可）
      

      

        ⑩-8 协议闸的口径比 ADR 写的更窄
        mailto: / //evil.com / 相对路径都被判「降级为不可点」，只有 http(s) 过闸（INV-7）
        ADR 只点名 javascript:/data:/file: ⇒ 实际口径是白名单（mailto 也拦）。要放 mailto 得在票一里明确加，别让实现自己猜
      

      

        URL 含括号时现状留残括号（顺带修）
        [a](javascript:alert(1)) 现状产物 a)；x_(y) 类维基链接同
        链接正则需允许一层括号；这是既有缺陷，可在票一顺手修并登记
      

      

        「样式类挂上了 ≠ 样式生效」——原型自己踩到了 uvue 那条规则要防的同一族 bug
        浏览器读数：外层 class="run r-b" 齐备，computed font-weight 却是 400（font:inherit 简写重置）；链接 .r-l 的蓝色被 .run{color:inherit} 按源码顺序盖掉。两处都必须 computed 读数才看得见
        票一的 ⑥-1 / ①a 判据不能停在「嵌套 <text> 上挂了 r-b」——要能证明计算后的样式真的生效（Web 侧 computed style / App 侧只能靠真机像素或 a11y 读数）。这条正是移动端 text-decoration 待验格同一个判据形状：别拿"写了"当"出了"
      

      

        摘要里的成对记号只有一个成因：围栏代码块原样入摘要
        ```…code **block**…``` 的帖子，列表摘要带着 **block**（#1273 投影对 code 块「用块 text、不再剥」）。生产既有行为，与 ⑩ 无关
        票一要么沿用并在回记里具名（「摘要含代码原文」是设计不是缺陷），要么让摘要跳过 code 块 —— 但别让它继续默默撞 #1273 那条「预览不含星号」的判据
      

    

  

  

    
原型答不出来的（见上一卡的「必须真机判」表）＋ 票二浮层的结论

    

      ⑪ 的联动逻辑（遮罩阻断阅读、面板 bottom 跟键盘高度、删掉「下滑收起」后触发条常驻、面板内滚动兜半屏）在 ④ 的合成键盘模拟里自洽：面板开着时 feed 不可滚 ⇒ #1300 那条判据的触发场景确实消失，删得对。
