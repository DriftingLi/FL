## 要回写给 ADR / 票一 AC 的 8 条（都是跑出来的，不是想出来的）

1. **`markdownInline.uts` 的分词必须递归**（run 要带 `kids`）。单趟扁平匹配下 `**粗体里有 [链接](…) 和 `码`**` 会把链接**源串留在粗体 run 里** ⇒ 正好打破 ⑥-1，而这是论坛帖的常见写法。
2. **⑥-1 的判据对象是「渲染产物按元素切段」，不是拼接后的整段文本**。跨 run 拼接会把代码内容里的 `**` 与远处一个裸 `**` 连成误报；而**只按 runs 判**又抓不到「某渲染分支压根没接 runs」——引用块就是这么漏的（原型实测：`esc(blk.text)` 直出 `**粗体**`）。⇒ 两条判据都要有。
3. **⑩-5「产物逐字不变」这句不成立，须按实改写**。实测 **6 类**源串投影会变，逐条都是修现状缺陷：裸 `*` / 词内 `_` **不再吃掉字符**（`a_b_c` 现状被抹成 `abc` —— 生产既有缺陷，学员贴变量名会丢下划线）、URL 括号不再残留游离 `)`、嵌套 `~~` 被剥、代码内容不再被误剥。⇒ 改口径为「只允许等于**修复集**的变化」，并**同步 #1273 那条「预览不含星号」的判据**（裸星号今后会合法出现在预览里）。
4. **摘要与渲染应共用同一次分词**（投影取 runs 叶子）。否则「渲染剥了 / 摘要没剥」只能靠用例逐个追堵 —— 现状的 `~~` 泄漏就是两处分道的事实。
5. **⑩-8 实际是白名单**（只放 `http(s)`）：`mailto:` / `//host` / 相对路径全被降级为不可点。ADR 只点名 `javascript:/data:/file:` ⇒ 要放 `mailto` 必须在票一写明，别让实现自己猜。
6. **新分词器不得接进 chapter / featured 的投影**（它们走 #1273 的「直接用块 text」）。本语料上二次剥恰好幂等 ⇒ **风险低但不是零，别拿幂等当许可**。
7. **围栏代码原文会进列表摘要**（`#1273` 投影对 `code` 块不剥）⇒「摘要含成对记号」的**唯一成因**就是这一条，**生产既有行为、非 ⑩ 引入**。票一要么沿用并在回记里具名，要么让摘要跳过代码块；不能继续默默撞第 3 条那条判据。
8. **「样式类挂上了 ≠ 样式生效」与 §6 的 `text-decoration` 待验格是同一族判据形状**。原型自己踩到：外层 `class="run r-b"` 齐备但 computed `font-weight` 仍 400（`font:inherit` 简写重置），链接蓝被 `.run{color:inherit}` 按源码顺序盖掉 —— **只有 computed 读数看得见**。⇒ 票一 ①a 不能停在「嵌套 text 上挂了样式类」，要出**计算后样式**的证据（App 侧即像素 / a11y 读数）。另：`text-decoration` 只在承载它的那层生效、子层读数为 `none`，在 uvue「子节点不继承父样式」口径下要按**外层 run** 来读。

## 更正（同日 · `/research` 回读一手文档后）

本文「原型的边界」一节有两条**已被文档回答，不再是空白**，以 `.scratch/md-inline-render-facts.md` 为准：

1. **「`text-decoration` 在 app(uvue) 端是否生效＝未过」不成立**。一手页原文：「app平台暂不支持 text-decoration **简写**样式，仅支持 **text-decoration-line**」；长形态兼容性表 Android **3.9** / iOS 4.11 / Web 4.0，属性值仅 `underline / line-through / overline / none`，适用组件 `text`、`button`，且官方示例直接在 `<text>` 上写长形态、未包 `#ifdef WEB`。⇒ 下划线与删除线**该画得出来**；原型的「App 受限模式」从"预期结果"降级为"兜底口径"。真正剩下的只有一格：**长形态作用在嵌套子 text（而非根 text）上的实际出图**。
2. **「`uni.onKeyboardHeightChange` 可能不存在」不成立**：Android 4.71 / 微信小程序 4.41 均有（只缺 Web，而本仓不产 H5）。票二 §6 那格收窄为"存在、但三者配合未验"，并须处理微信文档明写的两条：同 height 值去抖、`textarea` 的 `blur` 晚于页面 `tap`。

另外补一条**写法层面的硬约束**（原文件 ⑥-1 的判据形状不变，但样式实现要照它改）：每条 run 自带全量样式（App 端不继承、小程序端按 CSS 继承 ⇒ 取严的交集）、修饰线只写长形态、行内代码不用 `padding`、等宽不依赖 `font-family` 逗号回退。详见研究文件 C1–C4。
